# Native10 训练参数与审查决定

2026-09-16，分析端批准的训练设计补充。与 `NATIVE10_TRAINING_TASK.md` 一起使用；不修改已发布的 P0 配置/代码，不代表技术检查已经通过。

## 采纳与口径

采纳 `NATIVE10_TRAINING_DESIGN_REVIEW.md` 的候选、损失与两路径训练建议。训练 cut 比例统一以主任务书为准：**50% 首次合法报警、50% 预注册时刻**，不是审查草稿中的 70/30。原因是历史报警高度集中在 t=5，本轮需要更充分的后续执行状态覆盖。scheduled 默认在 15/45/95 三个时刻按任务/轮次均衡分配；未到达与无报警的 fallback 优先序在采集前冻结，禁止依据最终成败或候选效果选 cut。

开发策略/校准/保留使用首次合法报警的一次干预策略及全部预登记 episode 分母。训练 scheduled cut 只服务训练覆盖，不混入该策略成功率。其他时点/自然边界策略如需变为主方案，先登记独立方法修订。

## 两条训练路径均实施

| 项目 | A：残差适配参照 | B：小 critic 完整重训 |
|---|---|---|
| 初始化 | 旧四成员权重 | 新初始化四成员 |
| 可训练部分 | residual/advantage | 全部小 critic MLP，含 state/base/baseline/residual/advantage |
| 状态投影 | 原冻结投影 | 当前轮训练集重新拟合 PCA；保留视觉16/语言8维 |
| 大模型 | VLA/D/视觉语言特征提取器冻结 | 同左 |
| 学习率 | 1e-4 | 3e-4 |
| AdamW weight decay / gradient clip | .01 / 1 | .01 / 1 |
| batch | 32 完整 source | 32 完整 source |
| 第一轮最大更新 | 2400 | 2400 |
| 最终最大更新 | 4000 | 4000 |

检查点固定为 200/400/800/1600/2400/3200/4000，第一轮只到2400。最终基于两轮全部新训练数据重新训练各路径，B 重新拟合 train-only PCA，不把第一轮 PCA 下的旧权重直接接到不兼容的最终 PCA。四成员对 episode 按任务分层 bootstrap，保存抽样清单；同一 source 的候选与重复整体随行。主训练不使用按结局“有差异源四倍”的旧采样规则。

B 为必做主训练实验，不能以 A 的少量残差更新代替。两条路径均可早停，不要求把最大步数用完；数据覆盖与泛化决定选步。

## 损失及选择

对完整 source 的候选均值标签，固定：

`L = BCE_success + 1.0 * MSE_gain_to_a0 + 0.5 * MSE_positive_negative_probability_difference`。

每项先在该项有效候选/正反对内平均，再按 source 平均，明确 mask 和去重权重。a0 恒等锚定保持。正反项是已有真实标签的定向加权，不是无噪声梯度真值；不除以很小半径放大二值噪声。本轮不搜索损失权重。

每轮在同一开发候选银行上离线选择一个 A/B 集成 checkpoint：以预测最大成功率选候选（a0 并列优先），选择其真实配对净增益最大的模型；并列依次取 harm 更少、相对增益 MSE 更低、步数更早、B 优先。无报警 episode 保留相同结局，开发条件指标与总体指标分列。有限候选选择只是连续梯度方法的代理，必须再做本轮一次五臂实际开发比较。

每轮仅对离线选出的一个 critic 跑 100×5×4 比较；不得把 A/B 各跑一套而翻倍预算。第一轮已冻结模型用于第二轮所有新 source 的候选生成，第二轮不边采边改模型。最终在开发集选定一种主注入方式，再校准接受规则并冻结最终保留测试；其余方式列次要比较。
