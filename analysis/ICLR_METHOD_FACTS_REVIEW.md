# ICLR 材料：方法事实与可主张边界

日期：2026-09-18。用途：供总实验文档和标题/摘要起草引用。本文只整理已核中文算法文档、训练/执行/纠偏笔记和最终保留集解释；未新增模型调用、PCA、训练、仿真或统计检验。以下“可主张”指当前证据支持的描述，**不是对文献优先权或新颖性完成检索后的判断**。

## 1. 一段准确的方法概述

在冻结的 Pi0.5 VLA 上，正常策略从 episode 开始按 **10 个控制步重新规划**。系统每5步用旧的、冻结的 D/G0 预测换计划收益；首次合法报警时，采样一份新的动作计划 a0，以它为固定锚点，用四成员局部成功概率 critic 对首10步动作求梯度。比较 flow 末三步的两种引导方式与采样后的 post 方向，并在共享可行 mask、分组幅度和 raw 命令约束下执行一次修正；此后恢复普通 native10，不再报警或纠偏。最终选定的方法是 **A4000 critic 引导的 matched-post**，而不是持续多次干预的闭环控制器。

normal/N 是“忽略额外报警，保持正常 native10 周期”，不能称为完全不重规划。replan/R 在报警点丢弃旧队列余下5步，执行新 a0 的10步，再按 native10 续跑。R−N 包含新的动作与后续规划相位变化；post−R 固定新 a0、干预窗口和后缀相位，是纠偏相对额外重规划的增量主比较。

## 2. 数据：600个新训练源，不是31,200个独立状态

| 划分 | 独立 episode/source | 每任务 | 用途 |
|---|---:|---:|---|
| 第一轮训练 | 300 | 60 | 旧冻结四成员 critic 生成13候选 |
| 第二轮训练 | 300 | 60 | 第一轮选中的 B200 生成13候选 |
| development | 100 | 20 | 95个有效cut、5个共同结局；两轮复用，选模型及主注入方法 |
| calibration | 100 | 20 | 每源2后缀；只决定已定 post 的全局启用/关闭 |
| heldout | 100 | 20 | 每源4后缀；模型、方法和接受规则封存后一次打开 |

五个任务为 disassemble-v3、pick-place-wall-v3、shelf-place-v3、stick-pull-v3、stick-push-v3。按 episode 分组隔离；物理初态去重信息只用于采集审计，不输入网络。

训练每源一个主要cut，预登记一半首次报警、一半定时15/45/95；不可达时使用预登记较早合法 anchor，不按后续成功或Q挑切点。开发、校准、held 只用首次合法报警，没有训练的定时/fallback 规则。两轮均有300个实际有效训练cut。

**源轨迹始终由冻结 VLA/native10 执行。** B200只在第二轮恢复cut后生成局部候选，不在源 episode 中执行纠偏；真实标签来自环境续跑，不能称为在线策略迭代或 teacher Q 蒸馏。两轮合并的是相同定义的 PCA 前 canonical 观测特征，保留两套真实采集协议和生成 critic 身份，不拼接两套 teacher 的 PCA 坐标。

### 每源13候选与真实标签

| 槽位 | 候选 |
|---|---|
| 0 | 新 a0 |
| 1/2 | 最终 matched-post 的 XYZ 分量正/反向 |
| 3/4 | 最终 matched-post 的 gripper 分量正/反向 |
| 5/6 | 独立平滑随机联合方向，半幅正/反向 |
| 7/8 | 同一随机方向，全幅正/反向 |
| 9/10/11 | 正式 matched velocity/direct/post |
| 12 | reverse_post，即最终 post delta 取反 |

通道倍率按源预登记为0.5或1；post通道为零时使用独立随机 fallback并记录。随机方向按每维三个高斯时间节点线性插值。通道/随机对单独保证对称可行，**不把13个候选重新一起做公共半径匹配**。训练 reverse_post 与部署 matcher 的 reverse_direct 不同。

每候选执行首10步，再以冻结 VLA/native10 续跑到成功、环境终止或整条 episode 的300步上限。标签为是否出现 success 的二值结果。每源四次后缀随机流在候选间配对；四重复共享同一候选 bank，并非重新抽四份 a0。因此：

- critic 候选监督：**600×13×4=31,200 条二值 rollout 标签**；
- 另存 normal 控制：600×4=2,400 条；**不进 critic 损失，也不用于本轮重训 G0**；
- 独立训练状态单位仍是600个源，不能把候选或后缀当独立状态扩大样本量。

同源 raw 命令完全相同的 alias 候选在损失中去重；本次采集并未省略这些物理分支。clip 后动作相同不等于 raw 命令相同。alias组应具有一致配对标签；缺失四后缀不能填0。

## 3. Critic：锚定相对成功概率，不是环境真梯度

### 输入与容量

冻结视觉特征的“当前帧+历史均值”由8192维降到16维；2048维语言经无参数 LayerNorm 后降到8维；加20维本体历史、16维过去动作和1维剩余预算，共 **61维**。动作输入是首10步×4维。完整 MuJoCo 状态、恢复 fingerprint、真实未来和success标签不进入critic。

每成员5个 SiLU MLP：state 61→32→16、anchor-action 40→16→16、residual 40→16→16、baseline 32→32→1、advantage 48→32→1。每成员 **7,058 个网络参数**，四成员28,232；PCA、均值/尺度等预处理 buffer 不包含在该数字内。冻结视觉/语言提取器、VLA及D/G0也不包含在这个小 critic 参数量内。

令 f 为61维特征，b=C(a0_raw[:10])，C(a)=clip(a,−1,1)，a为候选critic动作，d=(.15,.15,.15,.40)按时间广播。定义

\[
u=[S(f),E(\mathrm{vec}(b))],\quad v(a)=R_\delta(\mathrm{vec}((a-b)/d)),
\]
\[
z(f,a;b)=H(u)+F([u,v(a)])-F([u,R_\delta(0)]),\qquad Q=\sigma(z).
\]

这里 Q 是“当前观测和固定 a0 条件下，执行该10步前缀后按冻结策略续跑”的有限时域成功概率近似；不是通用最优 Q，也不做 Bellman/TD 更新。在线目标为

\[
\mathcal J_s(a;b)=\tfrac14\sum_{m=1}^4[Q_m(s,a;b)-Q_m(s,b;b)].
\]

冻结观测、b和全部网络参数，只对候选动作求导。J(b;b)=0不要求候选梯度为0；基线项是固定锚点。四成员离散度没有用作接受门或置信区间。

### 真实训练损失

记 q_ij 为候选四个二值标签均值，G_i 为去重候选组，G_i^+ 排除a0组，P_i为去重的有效正反候选对。单源损失：

\[
L_i=\operatorname{mean}_{j\in G_i}\mathrm{BCEWithLogits}(z_{ij},q_{ij})
+\operatorname{mean}_{j\in G_i^+}\big[(p_{ij}-p_{i0})-(q_{ij}-q_{i0})\big]^2
+0.5\operatorname{mean}_{(j,k)\in P_i}\big[(p_{ij}-p_{ik})-(q_{ij}-q_{ik})\big]^2.
\]

权重固定1/1/.5；空gain/pair项为0，外层按完整source等权平均。正反pair来自 XYZ、grip、随机半幅、随机全幅及 post/reverse_post。

**这些是真实配对动作干预下的成功差监督，不是直接监督真实动作梯度。** pair项不除以扰动半径；环境不参与反向传播；没有排序hinge损失或可微仿真。可以描述为“用局部配对 rollout 学习可微的相对成功率替代目标”。

## 4. A/B训练与最终A4000

| 项目 | A：旧critic残差适配 | B：全小critic重训 |
|---|---|---|
| 每阶段起点 | 原旧1041–1044四成员 | 四个全新MLP |
| 可训练部分 | residual+advantage：2,529参数/成员 | 全部MLP：7,058参数/成员 |
| 冻结部分 | state/anchor-action/baseline及旧PCA/全部预处理buffer | 当前train拟合后固定的PCA及全部预处理buffer |
| PCA | 原成员旧投影 | 当前阶段唯一有效train源各用一次，16视觉/8语言 |
| 学习率 | 1e−4 | 3e−4 |

四成员按任务进行完整source bootstrap；最终每任务120次抽样，总600，候选和后缀不拆开。minibatch32源；AdamW、weight decay .01、梯度范数上限1；第一轮每成员2400更新，最终每成员4000。两条路径均实际训练到上限，总更新19,200+32,000=51,200。新PCA只看train；开发/校准/held不进入损失或PCA统计。

**最终A重新从原旧四成员开始，不是接着首轮A训练；最终B在600源上新拟PCA并重新初始化，不是接着B200训练。** 预检封存的权重/PCA/bootstrap/minibatch/mask随后被真实训练直接复用。

同一固定开发13候选 bank 比较各A/B ensemble checkpoint，规则依次为：完整100源配对净收益最大、损害少、相对收益MSE小、步数早、最后并列优先B。四成员使用同一checkpoint步数。首轮选B200，最终选 **A4000**。该离线候选选择代理与真实连续梯度 rollout 不同；每轮仅所选critic再做一轮实际五臂开发评价。

A的局限是a0基线分支没有适配新数据的自由度；新训练主要调整相对动作部分。A胜出不能证明冻结状态优于全量训练，也不能证明旧PCA或残差设计是收益的唯一原因。部署时A的2,529参数也全部冻结，“可训练参数”只描述拟合阶段。

## 5. G0是保留的旧模块，有明确协议差异

D为两个冻结动作条件预测模型；G0为两个冻结收益回归头。D提供旧队列接下来5步的预测视觉效应，G0输出预期换计划收益，不是视觉预测误差，也不是失败概率。报警门为两成员均值严格大于.05。

旧G0目标是

\[
y_G(s)=\tfrac13\sum_{j=1}^3\widehat p(\text{fresh}_j\text{执行5步，再fixed10})
-\widehat p(\text{old执行5步，再fixed10}).
\]

历史训练40个有可达cut的source提供 **80个cut级标签**；每cut四候选×两后缀，共640个候选结局。旧验证39cut/312结局。640不是640个独立G0状态。D预测按source交叉拟合供G0训练。

旧source规划horizon混有20/50，fresh前缀5步；当前source是native10、干预承诺10步。**本次600新源只训练动作critic，未重训G0/D。** 因此可称“冻结收益门下的动作纠偏”，不能称“新学得并校准了native10中断收益门”。门限.05不等于5%错误概率，也不保证当前额外重规划必有5pp收益。

## 6. 三种引导与matched-post的完整定义

内部flow状态 x_tau 为50×32，Euler从tau=1走到0，步长−.1，10次网络调用。clean估计u=x_tau−tau*v。动作反归一化U(u)=mu+S*u，S=(q99−q01)/2，评分变换T=C∘U；目标只读首10步、前4维。

| 方向 | 实际定义 | 固定设置 |
|---|---|---|
| velocity | v_tilde=v−alpha*tau*g_u，g_u=grad_u J(T(u);b) | tau=.3/.2/.1，alpha=10 |
| direct | v_tilde=v−alpha*g_u | 同上 |
| post | d_P=S²⊙grad_a J(a;b)在a=b处求值 | 无引导采样结束后一次梯度 |

V/D固定当前x与网络输出v的数值副本求导，不计算VLA Jacobian，不跨采样步反传；后续前向仍响应变化后的flow状态。负Euler步长使上述减梯度产生正向局部位移。post用S²保留对应内部坐标的度量，不再运行一次flow；三者都无回溯或逐源Q准入。

实际执行方向不是未经约束的上述原生更新。部署构造五方向：V、D、P、−D、平滑随机；对XYZ和grip分组做共同mask与RMS归一化，目标RMS分别.05/.10，单坐标上限.15/.40，边界余量至少.05。**实际公共半径取五方向全部可行上限和目标半径的最小值**；任一方向某组为零会共同关闭该组，不删除源。V/D很小的原生方向也可能被归一化放大。

在有界critic坐标计算delta，再加回同一原生raw a0；mask外、零delta及尾40步保留原始raw位模式。R不额外clip，N不被新a0覆写。reverse/random只生成用于匹配，并非第六/第七个物理评价臂。

**最终固定post仍需生成V/D/reverse/random来确定共享半径。** 当前成果应叫完整 matched-post；删掉其余方向、改成单独post自身半径，属于尚未评价的算法变化。held完整bank均时1.3347秒（不含恢复），post梯度子步3.564毫秒；后者不能作为完整纠偏时延。恢复/审计是评估过程开销，完整bank也不等同经过专门优化的真实机器人部署延迟。

## 7. 当前证据支持怎样写贡献

### 可据实写的内容

1. **问题拆分与对照设计。** 在相同native10基础策略下，把报警后额外重规划与动作纠偏分开评价；纠偏臂共享a0、初始flow噪声和配对后缀，避免把新采样本身的收益算作梯度收益。
2. **方法组合。** 用新采集的局部正反/随机/梯度候选终局成功标签，训练锚定a0的相对成功率critic，再对冻结flow VLA作受约束推理时动作修正。VLA不需再训练；不等于整个系统无需训练或无需仿真数据。
3. **注入位置比较。** 比较两个flow内注入与一个采样后方向，并以共享mask和公共可行幅度约束控制最终动作差异。它控制幅度，但不是对所有机制都完成单因素消融。
4. **独立保留集结果。** post在打开held前固定；五任务100个不同初态、每任务20、每源4配对后缀，成功率62.5%对R的53.5%，主增益+9.0pp，源级95% CI [3.25,15.00]。区间支持平均正收益，不能写成真实增益至少5pp。

以上可以作为贡献候选，最终“新颖”程度须由完整相关工作比较决定；不得写“首次”“普遍优于现有方法”或“达到SOTA”。当前三注入是本系统内比较，不是对GAF/QGF/QPILOTS等方法完成复现后的外部排名。

### 当前仍缺的消融/泛化证据（不是已完成实验）

- 新数据量、局部数据分布、两轮teacher更新各自贡献；阶段间开发/校准/held差值不能作训练量的因果证据。
- BCE、相对a0损失、正反pair损失、锚定结构、旧权重/PCA、四成员ensemble分别是否必要。
- matched半径相对原生半径的作用；S²坐标度量、随机方向、反向方向是否优于更简单替代。random/reverse没有独立物理测评臂，不能声称已证明梯度比所有非梯度方向好。
- 单独post与完整bank post的收益/成本权衡；当前不能把bank依赖删去后沿用held结论。
- 重新匹配native10的G0、重复多次纠偏、跨任务/模型/环境/真机，以及多次独立完整训练种子的稳定性。

## 8. 摘要写作时的禁止外推

| 容易误写 | 与证据一致的表述 |
|---|---|
| 31,200个独立训练状态 / 真梯度标签 | 600源，31,200个配对候选rollout二值标签；学习可微替代目标 |
| 第二轮在线纠偏采集 / 策略自我提升 | 源策略冻结；第二轮更新局部候选生成critic |
| 端到端微调VLA | 冻结VLA；训练小critic，推理时只对动作求导 |
| 已校准的纠偏置信度或安全门 | 四成员平均预测目标；没有逐源Q接受门 |
| 无需仿真、数据或额外计算 | 需要真实环境分支标签；评估依赖可恢复仿真 |
| 单步post完整耗时3.564毫秒 | 该数仅梯度子步；完整matched bank平均1.3347秒，不含恢复 |
| 参数极少的完整系统 | Q每成员7,058网络参数；VLA、D/G0、特征提取与预处理存储另计 |
| 成功率提升9% | 相对R的绝对成功率提升9.0个百分点 |
| 每任务均已显著改善 | 五任务点估计均为正；没有据此证明各任务分别显著 |

held中98个报警源的post平均Q预测+11.06pp，实测+9.18pp；逐源Pearson仅.223，六个净损害源Q均为正。平均预测接近平均收益不等于逐源校准，更不能用它认定损害的唯一机制。完整100源主增益+9.00pp与98个报警源的+9.18pp必须分开。
