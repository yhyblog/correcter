# SmolVLA / X-VLA 小批量推理效率补测，2026-09-25

本次根据用户“针对缺失的效率数据，进行小批量的测试，来获得网络对于推理效率的影响”的新授权，补测现用 SmolVLA050000、X-VLA030000 及各自 L11/fit9101 辅助网络。训练权重、控制接口和动作尺度沿用最终实验版本。此前 π0.5 的独立查询测速保留为历史数据。

每个底座从按名称排序的 MT50 任务中等距预定 20 个任务，每任务一个固定新初态和策略种子。执行本底座的前五个真实环境动作，获得合法观测历史、旧动作队列和切点。到切点前结束的源如实记录，不制造切点或成功率。这里只测查询耗时，不重复完整成功率评测。每 GPU 一个原生策略进程及其外部特征服务，batch size 为 1；四张 GPU 测一个底座，共八张 H100。特征服务与原生策略在同一卡上依次接受该源请求，无同卡并发查询。

每个合法切点对 N（正常完整策略采样）、R（完整 fresh 采样）、Post（fresh 采样、四成员 Q 动作梯度、自身半径投影）各预热一次，随后各计时五次，轮换执行顺序，计划每底座每方法 100 次有效查询。R 与 Post 使用配对候选种子。测量期间不推进环境，因此测量的是相同真实输入上的查询开销，不是闭环 episode 耗时。N 使用自然采样流，R/Post 使用隔离的候选随机数流。所有测量样本保留；不根据成功率或延迟筛选任务、网络、阈值或重复实验。

查询计算时间覆盖输入预处理、完整原生采样和动作反归一化；Post 另含 Q objective 构造、动作梯度和投影。GPU 计算在计时边界同步，Q 按历史实现保留在 CPU。记录逐查询计算时间和含本地通信的调用墙钟时间。D/G0 监测另测外部 π0.5 历史视觉编码、上下文准备、两个 D 成员、两个 G0 成员及整段监测调用时间；语言特征按任务缓存。查询表中的 Post 不包含前置监测，完整辅助开销需结合该独立监测表解释。模型加载、环境步进、渲染、首次预热不进入查询均值/P95；相加组件只用于单次查询均值对应的实际路径，P95从逐查询总耗时计算，不把分项P95相加。

Smol 保留原生动作反归一化导数平方；X 保留已验证的外部 π0.5 S² 桥，并只在 Q 接口将 raw30 补到50，最终返回 raw30。单次 Post 不生成 Velocity 或 Direct。此次测试使用已训练的小网络，不使用文档中尚未训练的扩容方案。

使用独立有限队列、当前主机实际 GPU UUID、当前原始执行线程及独立日志。正式进程族内八卡 holder 全部关闭，全部自有子进程退出后由本机 guard 恢复。总预算一小时，模型就绪等待至多二十分钟；工程失败和缺项保留在结果中，后台自动汇总现有有效计时并登记终局通知。原始逐查询记录、组件统计、源覆盖和硬件身份保存在本目录，统计量描述这批小规模真实上下文。
