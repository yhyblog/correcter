# π0.5 与 D/G0 的并发反馈、宽度512 Q完整路径测速

按用户2026-09-26授权，固定H10、动作时钟30Hz，对应不打断时每秒三次策略请求。本次实际运行π0.5 MT50 SFT030000，两个已训练D、两个已训练G0，以及四个随机初始化的宽度512 Q（每成员3,781,122参数）。用户已确认干预包含Q动作梯度；沿用S²与自身半径投影，省去每次权重哈希、调试分支及额外确认。没有训练或成功率实验。

每GPU只有一个独立输入流与一个π0.5模型副本，策略采样与反馈在同一GPU的两个CUDA stream、两个工作线程中执行。冻结视觉权重共享，预处理器和采样随机数流分别持有；各自等待自身stream，查询中不做全卡同步。Q保持当前CPU部署、FP32、两个CPU计算线程。每次策略生成raw50，执行承诺仍为10，采样10个flow步。反馈包含五帧真实图像的编码、上下文准备、两个D→G0对以及输出传输，不把缓存好的视觉特征耗时当作整条反馈耗时。

输入复用此前保存的五任务各四源cut5真实快照，加载和任务语言准备在计时外完成。四张GPU各承担五个上下文；每个上下文每种路径预热一次、测五次，每格100次。主计量为从外层提交请求到结果动作可用的实测墙钟，不相加分项时间，也不以max代替执行。

四种路径分别为：N只发起π0.5请求；已需采样新计划时，同时发起π0.5与反馈而不纠偏；同样同时发起两者，收到二者后执行Q梯度与投影；队列中途由反馈决定重规划时，先取得反馈，再发起新计划采样并纠偏。前两种并发路径均只有一次策略采样。第四种保留反馈决定新采样的真实先后关系，不将其误称为可以完全重叠。测试直接指定是否走干预路径以覆盖成本情形，同时保存实际G0输出，不据得分挑选样本。

另四张GPU各运行一个独立反馈频率轨迹，采用30Hz输入到达参考时钟与3Hz常规策略释放时钟，记录实际调用起止。分别测策略单独3Hz、反馈单独持续运行、3Hz策略同时6Hz反馈、3Hz策略同时30Hz反馈，以及3Hz策略同时反馈持续运行。除单独反馈5秒外每段10秒；过期输入仅保留最新一份，跳过数量单列。记录逐次反馈延迟、实际每秒完成数、策略333.33ms期限命中率与未达频率的原因，不把多GPU总吞吐写成单卡反馈频率。

频率轨迹重复使用已保存的真实输入张量以测计算服务，不运行仿真步进或机械臂；它衡量该部署的推理管线并发能力，未包含相机采集和机械臂通信。加载、预热、输入文件读取不进入推理时间。整波正式进程持有一个生命周期预约、全部holder停算，全部子进程退出后恢复；模型等待最长900秒，总预算1800秒，完成后自动汇总并通知原执行线程。
