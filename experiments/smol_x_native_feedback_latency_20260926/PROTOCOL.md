# SmolVLA/X-VLA 原生视觉反馈延时

本轮依据用户2026-09-26的新增授权，测两个底座不带D/G0的原生采样，以及使用各自视觉特征后的完整D/G0反馈。不训练，不测成功率。H=10、动作参考时钟30Hz、常规策略请求3Hz，原生采样各10个flow步；Smol返回raw50，X返回raw30。本轮不含Q。

每卡一份冻结底座，在两个线程和两个CUDA stream中共享视觉模型，策略与反馈预处理器独立。Smol使用自身vision tower及connector产生8×8×960空间特征，X使用Florence-2视觉编码器产生7×7×1024空间特征。每次反馈在线编码五帧，逐帧batch1；空间池化至4×4，经过固定随机正交通道投影至256，形成4096维输入。语言来自各自底座的token embedding有效位均值，补零至2048维，按任务提前缓存。反馈内的预处理、视觉编码、池化、投影、张量准备、两个D→G0对和门控输出传输均计时。没有外部π0.5模型或其视觉/语言特征。

D保持width256、G0保持width128，各两个成员；由于旧权重在π0.5特征空间训练，本轮重新随机初始化，归一化均值0、标准差和delta_scale为1，保持模型接口和计算结构。测试仅衡量这一输入适配的计算成本，不把随机门控输出用于选择是否运行样本。

原20260925 Smol/X测速只保存了40源上下文元数据，没有保存RGB。因此本轮改用刚完成π0.5并发测试的20个真实cut5快照，让两个底座读取同一组RGB、proprio、实际动作前缀及队列；轨迹来源仍标记为π0.5历史轨迹。旧快照中的π0.5编码特征不读取。输入文件读取、语言缓存及模型加载在计时外；计时内从CPU图像预处理至CPU输出，整段动作统一后处理和传输。

八卡按两个底座各四卡分配，每卡五个上下文。每个上下文测原生N、完整反馈monitor、策略和反馈同时启动且不干预三条路径；每路径预热一次、测五次，每底座每格100次，合计600次有效查询。主结果为实际外层墙钟，不相加分项，也不以最大分项代替执行。

随后每卡用其第一上下文回放五种频率模式：策略单独3Hz、反馈单独满速、策略3Hz加反馈6Hz、策略3Hz加反馈目标30Hz，以及策略3Hz加反馈持续满速。反馈单独运行5秒，其余每段10秒。跳过过期输入、保留最新输入；统计每卡真实完成吞吐、期限超时与跳过次数。这个频率试验不含机器人通信、相机采集或环境步进。各卡结果取均值和范围，不将多卡吞吐相加写成单卡频率。

本机全部holder在正式波次内停止，包括加载及提前结束卡。有限后台队列最多1800秒，完整退出后自动汇总并通知原执行线程；完成单元不重跑，工程失败原样保存。
