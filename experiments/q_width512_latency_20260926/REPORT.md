# 宽度512 Q：仅前向推理测速

设备：CPU（Intel(R) Xeon(R) Platinum 8480+），FP32，2线程，batch1。随机初始化，无训练。

保持既有Q的五个MLP、锚点/候选两槽、零差优势校正和四成员平均概率。状态61维，动作10×4；预处理接口尺寸的固定随机输入。每种配置预热20次、计时100次。只包含前向推理，不包含梯度、哈希、投影、D/G0、VLA或通信。
