# SmolVLA/X-VLA 原生反馈并行加宽度512 Q纠偏

用户要求核查Smol完整反馈34.947ms并增加并行Q纠偏。本轮只运行新路径：同卡同时提交原生策略采样和原生视觉D/G0反馈，二者返回后执行四成员宽度512 Q前向、动作梯度、S²和自身半径投影，直到修正动作可用。已完成N、单独反馈、不纠偏并行及频率窗口直接引用旧结果，不重复运行。

复用上轮20个真实cut5 RGB、本体与动作快照，以及同一Smol/X原生视觉适配、随机D/G0和随机种子。每次完整反馈重新逐帧编码五帧，含空间池化、随机通道投影、两对D/G0；为CPU Q返回当前观察张量的GPU到CPU传输也进入本轮反馈计时。语言embedding按任务预先缓存。原生策略各10步采样，执行H10、动作时钟参考30Hz。策略和反馈在独立线程、独立CUDA stream中共享冻结底座；每条路径返回前等待自己的stream，外层墙钟不是分项相加。

Q每成员3,781,122参数，四成员共15,124,488，随机初始化、CPU FP32、两个计算线程。保留原Q五个MLP和锚点/候选两槽，使用原生观测的8192维视觉摘要与2048维语言，经新固定随机正交投影得到16和8维，加37维本体/动作/剩余时间，组成61维状态。均值0、标准差1，不加载旧π0.5特征空间训练的预处理参数。动作残差尺度沿完整Q设置为[0.15,0.15,0.15,0.4]重复10步。

八张H100按两底座各四卡分配，每卡五个上下文，每上下文预热一次、正式五次。每底座新路径100次，共200正式查询和40预热。本轮不训练，不评价门控或纠偏正确性；测试指定走纠偏路径以覆盖其计算成本。无环境步进、相机采集或机械臂通信。
