# 小型纠偏critic：当前参数口径与必要验证

更新：2026-09-19。状态：按用户最新主张收敛修订；未启动训练、推理或仿真。

本文件替代上一版容量非劣实验计划。用户希望展示小型纠偏模块的效果，但没有提出“小模型不劣于大模型”或“比VLA微调高效”。因此不再默认进行三尺寸×两损失×三seed容量研究。当前实验以[总计划](Experiment_plam.md)为准。

旧版本完整保存在[历史容量研究方案](archive/PARAMETER_PLAN_before_scope_review_20260919.md)，其中参数公式和条件性设计可供未来查询，训练矩阵、3pp非劣、六项确认假设、10/22臂和资源数字均不是当前执行要求。

## 1. 当前可以验证并表述什么

- 使用28,232个网络参数的纠偏critic，在冻结VLA上能否提升实际成功率：由总计划E4及E1回答。
- 在不同VLA/环境适配后是否仍有效：由E8回答；各设置重新核算参数。
- 模块大小与实际部署开销是多少：准确计数，按E5在既定主实验内记录调用和时间，不新增评测episode。

这些证据支持“一个小型critic即可带来有效纠偏”。它们不证明小critic与更大critic性能相当、参数最优或比VLA微调高效。

## 2. 参数账本

| 组件或口径 | 当前数值 | 解释 |
|---|---:|---|
| 四成员Q网络全部MLP权重 | 28,232 | 部署critic的完整网络参数 |
| A4000本轮更新E_delta/F_adv | 10,116 | 继承旧critic后更新的部分，不是部署模型总大小 |
| 冻结D/G0 | 11,884,298 | 共同监测与收益触发网络 |
| D/G0/Q全部外接网络 | 11,912,530 | VLA另计 |
| PCA与归一化buffer | 待按dtype/元素统计 | 不算可训练权重，但计存储和内存 |
| VLA | 按实际checkpoint报告 | 冻结不等于部署时不存在 |

本项目28.2K的Q与VLA-Corrector约40M的LVM承担不同功能，不能只拿这两个数证明整个系统缩小上千倍。完整外接系统约11.9M；外部方法的缺失参数数据标NR。见[公开结果汇总](../references/vla_guidance/REPORTED_RESULTS_20260919.md)。

## 3. 当前所需实验

不为“小参数”单独增加训练模型。

1. 从总计划E4取得同协议Baseline、R、Post、Velocity成功率；从E1取得同参数BCE/Full比较。
2. 核对实际checkpoint的网络总参数、本轮更新参数、固定buffer和文件大小。
3. 在原定评测中预先划定共同计时子集，固定硬件、精度、batch、并发条件与范围，对本来就要运行的R/Post/Velocity入口记录均值、中位数、P95及预热。只取得并发日志时，限定为该运行条件下的观察时间。
4. 从主实验日志统计实际采样次数、干预次数、episode推理成本。当前R/Post/Velocity每次干预入口的完整采样数分别为1/1/2，不能都记为一次“纠偏调用”而掩盖内部采样差异；episode总采样数还包含正常重规划。

不要求容量扫描或新增成本实验；可以由已有H扫描直接计算success-per-call、调用/成功、推理时间/成功及成本曲线。失败代价进入分子，成功子集均值不作为唯一效率依据；公式和共享前缀的部署成本还原见总计划E5。其他模型适配后的参数与成本作为对应实验表的附列。

## 4. 以后什么情况下才需要恢复容量对照

仅当明确新增以下主张时：“与更大的同类critic相比，显著减少参数且保持任务性能。”

届时需要同数据、同表示、同初始化类型与训练机会的大小模型比较；不能拿继承初始化的小A4000对fresh大模型归因于参数量，也不能把差异不显著当成非劣。

历史方案中的S/M/L设计仅供这种新主张下重新审定。它不再是完成当前论文主线的前置条件，不沿用旧预算自动执行。
