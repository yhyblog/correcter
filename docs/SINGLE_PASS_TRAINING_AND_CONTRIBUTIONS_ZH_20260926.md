从零单次训练 D / Q → G0 的算法规划与贡献对应（2026-09-26）

本方案以固定的基础 VLA 和特征接口为起点，D、Q、G0 各成员从随机初始化完成一次训练。D 与 Q 可以独立训练，最终 Q 冻结后再采集 G0 的纠偏收益标签并训练 G0，随后直接组成允许多次干预的在线控制器。这是后续重训方案，历史权重与历史实验仍采用原记录中的监督协议。

三项贡献保持为：利用动作条件动力学信息、在新计划采样前进行收益触发；围绕固定新计划锚点进行绝对结果、相对收益和成对局部差值监督；每次干预使用一次动作梯度形成考虑坐标尺度且受幅度约束的短前缀纠偏。新的监督协议将 G0 的干预分支直接对应最终 Q 生成的纠偏 C10，并用 H 与队列剩余承诺长度表达控制配置。

参考策略 μ_H 是普通 VLA 控制器。对保留旧计划的分支，它继续执行原活动队列，到原本的自然规划边界才重新采样，此后一直按 H 执行。对已经执行候选 C10 的分支，它在候选结束时丢弃未执行尾部，从当前观测重新采样普通 H 计划，此后一直按 H 执行。两种入口沿用同一普通控制规则及各自实际的队列相位，终局预算均从 episode 开始计算。参考后缀中没有额外收益触发。

令 x 表示切点的历史、旧队列、执行相位、H 和剩余预算，Y 表示终局成功，b 为新计划 a₀ 的动作锚点。动作条件价值的目标为

\[
q_H(x,a)=P\{Y=1\mid x,\ a\text{ 执行 }C=10,\ \text{随后 }\mu_H\}.
\]

Q(x,a;b,H) 通过真实候选终局结果拟合这一目标，锚点 b 用于参数化局部动作比较。候选来自 a₀ 及其预设随机扰动，训练 Q 时不需要已经训练好的纠偏器。损失仍为 BCE + gain + 0.5pair，候选与锚点保持同源配对，正反候选共享局部扰动方向及参考后缀协议。

冻结最终四成员 Q 集成后，将完整在线纠偏过程记为 T_Q(x,a₀)：对这份新计划求一次集成目标的动作梯度，沿既定坐标缩放和有界幅度规则生成纠偏 C10。G0 的监督目标定义为

\[
A_H(x)=
\mathbb E_{a_0\sim\pi_\theta(\cdot\mid\mathrm{obs}(x))}
\left[q_H\bigl(x,T_Q(x,a_0)\bigr)\right]
-V_{\mu_H}(x),
\]

其中 V_{μ_H}(x) 是从当前切点保留活动队列、随后按普通 μ_H 运行的终局成功率。G0 训练标签取自两条分支的真实终局结果，不使用 Q 的预测成功率代替环境结局。纠偏分支对新计划采样和后缀随机性取平均，继续分支按原队列和规划时钟执行。两条分支允许有不同的首次自然重规划时刻，例如 H10、旧计划年龄5时，继续分支再执行5步就自然重规划，纠偏分支则执行完整C10。

G0 学习的是固定 VLA 与固定 Q 共同定义的替换操作的期望收益。离线采集可以生成新计划、纠偏并运行到终局，在线 G0 输入仍只包含决策前可见的历史、旧动作、D 预测和控制标量。因此，终局收益监督与采样前决策同时成立，在线无需提前生成新计划或运行 Q。实际网络对其有限输入进行收益回归；没有输入的队列尾部与未来随机性由训练分布下的条件平均体现。

| 网络 | 输入与监督安排 | 一次训练结束后的用途 |
|---|---|---|
| D | 历史、给定旧5步动作 → 未来5步视觉/本体状态；共享普通轨迹与随机分支转移数据 | 冻结后提供动作条件动力学预测 |
| Q | 原状态特征增加 H；固定新计划锚点与候选C10；候选后接相同H的普通参考策略 | 冻结最终四成员及纠偏配置，生成 G0 标签中的实际纠偏动作，并用于最终部署 |
| G0 | 原输入增加 H 和旧队列剩余承诺步数；D 的冻结预测；监督为上述真实配对收益 | 冻结后在每个合法监测时刻判断是否调用替换与纠偏操作 |

H 与剩余承诺步数使用固定尺度归一化。D 的预测长度保持5步。按当前宽度方案，G0 h=256 在收益头追加两个标量会增加512个参数，每成员由3,226,881变为3,227,393；Q w=512 的状态输入由61维变为62维，增加1,024个参数，每成员由3,781,122变为3,782,146。上述计数按已有结构直接推算，具体实现后核对；两个D、两个G0、四个Q成员的配置保持不变。

训练安排是先按源划分训练和测试集合，组织普通轨迹与 Q 的随机候选数据，在训练覆盖范围内记录并分层安排 H；再分别训练 D 与 Q，各成员按预先确定的步数完成一次拟合并固定末步权重；随后用最终冻结的 Q 集成采集“纠偏C10／继续原队列”的真实配对结果，用已冻结 D 生成输入特征，训练 G0 一次；最后固定全部网络，在独立源上运行完整 multi 控制器。D 的训练源与用于检查 G0 泛化的源在数据划分时安排，输入预测由一次训练后的冻结 D 生成，这一单次训练方案不再为 G0 额外训练交叉拟合 D。以配对终局差的均值为回归目标时，G0 采用均方误差最直接地对应条件期望；历史 SmoothL1 配置属于旧权重记录。

```mermaid
flowchart LR
    A[固定基础 VLA；普通轨迹与随机候选] --> D[D：训练一次并冻结]
    A --> Q[Q：锚定差值监督；训练一次并冻结]
    Q --> B[用最终 Q 采集纠偏 C10 与继续队列的配对终局]
    D --> G[G0：采样前期望收益；训练一次并冻结]
    B --> G
    D --> P[部署：收益触发、采样、单步有界纠偏、C10 后恢复监控]
    Q --> P
    G --> P
```

在线控制保留正常 H 队列、每5步监测、采样前触发、每次只生成一份新计划、一次动作梯度、C10 承诺和承诺结束后恢复监控。任务未结束且满足合法条件时可以再次触发。后续再次触发使用同一个 A_H 的学习估计，无需重新训练辅助网络。

固定参考策略的价值可以用于构造新的、反复决策的控制器，而不要求参考后缀等于新控制器全部未来行为。Rollout 文献明确区分一次策略改进与反复训练的策略迭代，并讨论在线重规划；这里借用的是这一解释框架，训练流程仍是离线一次监督学习。[Bertsekas, Multiagent Reinforcement Learning: Rollout and Policy Iteration, 2021](https://www.mit.edu/~dimitrib/Multiagent_Sinica_2020.pdf)

针对本方案可单独陈述如下理想化推论：若扩展状态充分，在新控制器可能访问的每个扩展状态上都能准确估计随机替换操作的期望优势 A_H，并且每次只选择参考优势非负的干预选项，那么将纠偏C10视为一个有持续时间的动作选项，有限时域反向归纳可得到新控制器的终局成功率不低于参考策略。归纳时，保持分支采用参考动作；干预分支在C10结束后进入已经满足归纳假设的状态，其参考收益又不低于当前参考价值。这个推论说明普通参考后缀与重复干预在定义上可以相容。该推论是本方案在理想条件下的推导，不是对神经网络估计误差、有限历史输入或实际部署表现的已验证保证。

论文据此将 G0 解释为“替换操作相对普通参考策略的期望终局成功优势”。分数阈值处于这一参考优势的单位下，不将它解释为最终 multi 控制器每次干预的已校准收益，也不把各次分数相加作为 episode 总收益。评估分别检查参考协议下的收益预测，以及完整 multi 控制器的成功率、干预次数和计算成本。

| 贡献 | 保留的核心机制 | 本次规划带来的对齐 |
|---|---|---|
| Gain-based selective replanning | 动作条件动力学信息；终局收益学习；新计划采样前决策 | 标签对应最终 Q 产生的实际纠偏 C10；显式条件化 H 与队列相位；对替换计划的随机性取期望 |
| Anchored local-difference supervision | 新计划固定锚点；绝对结果、锚点相对收益、成对局部结果差 | 所有候选使用同一 H 的参考后缀，原 L11 三项监督保留 |
| Bounded single-step post-sampling correction | 一份新计划；一次动作梯度；坐标感知且幅度受限的 C10 修正 | G0 采集与在线使用相同的最终纠偏算子；执行后恢复正常规划与监控，允许多次干预 |

第一项贡献可使用如下英文表述，另外两项贡献保留原有机制与措辞：

> **Gain-based selective replanning.** We introduce a learned intervention rule that uses action-conditioned dynamics information to predict the expected terminal-success gain of replacing the active plan with a subsequently sampled and corrected plan, making the decision before the replacement is sampled. We define this gain relative to preserving the active plan under a shared ordinary-policy continuation.

对应中文为：我们提出一种学习得到的干预规则，利用动作条件动力学信息，预测以随后采样并纠偏的新计划替换当前活动计划的期望终局成功率收益，并在采样替换计划之前做出决策。该收益以保留活动计划为参照，采用共同的普通策略后缀进行定义。

完整方案的创新表述、监督定义和执行规则由此对应起来。Q-free 的 R 仍可作为删除纠偏模块的执行消融；若复用这里的 G0，其分数语义仍对应完整替换与纠偏操作，R 的结果作为固定网络组件消融解释。
