## 1. 本文要回答的问题

当前确定的范围：

## 3. E1：L00、L10、L01、L11究竟表示什么

### 3.1 两位数字是开关，不是权重

定义：

    L_ab = L_success + a × L_gain + 0.5 × b × L_pair
    a,b ∈ {0,1}

第一位表示是否启用gain，第二位表示是否启用pair。success BCE始终存在。“L01”的1表示pair开启，实际权重仍为0.5；“L00”不是不训练。

| 旧简称 | 建议表中显示名称 | 实际训练目标 | 回答的问题 |
|---|---|---|---|
| L00 | BCE-only | success BCE | 普通成功率监督已能做到多少 |
| L10 | BCE + gain | success BCE + gain | 候选相对a0的收益监督有什么作用 |
| L01 | BCE + pair | success BCE + 0.5pair | 正反候选差监督有什么作用 |
| L11 | Full loss | success BCE + gain + 0.5pair | 两种差值监督合起来是否有效 |

### 3.2 三项损失分别学什么

记a0为同一状态下的无引导新计划，a+、a−为一对正反候选，p̂为执行候选后的经验终局成功率。

- success：预测每个候选本身的成功概率，与p̂做BCE。
- gain：预测Q(a)−Q(a0)，与p̂(a)−p̂(a0)做平方误差。
- pair：预测Q(a+)−Q(a−)，与p̂(a+)−p̂(a−)做平方误差；不要求每个源的全部候选两两配对。

例如a0、a+、a−分别成功2/4、3/4、1/4次：success看到0.50、0.75、0.25；gain要求a+相对a0提高0.25；pair要求a+与a−的差为0.50。

三项用的是同一批观测结局。gain/pair不是新增标签信息，而是改变训练时对局部差异的强调；最终有没有益处由新动作的真实成功率决定。仅打乱四次后缀标签的排列不改变候选均值，也不改变这两个损失，不做这种无效消融。精确的去重、空集合及源权重规则沿用[算法文档](../NATIVE10_CORRECTOR_ALGORITHM_ZH.md)。

### 3.3 最小充分安排

- MetaWorld现有五任务、π0.5、H=10。固定训练数据、候选bank、初始化来源、PCA、网络、更新模块、训练预算及开发选模规则。
- 四种训练目标分别接Post与Velocity，共8种纠偏配置；N/R/Full若与主实验模型、初态和协议完全一致可复用。
- 主要比较是Full loss−BCE-only，Post、Velocity分别报告。Full−L10是去掉pair的影响；Full−L01是去掉gain的影响。
- 建议三个完整训练seed。ensemble四个成员不是四次独立训练；相同旧初始化下的训练重复也不等于验证所有可能初始化。
- 采用当前A路径时，各格都从同一旧critic出发，只更新相同残差模块；结论明确为本轮学习目标的增量。当前旧Full只是一个固定模型，不能充当三个训练seed。
- 五任务消融若复用600源训练，其Full对照也必须来自同一600源训练流程。MT50主模型若使用新增50任务训练数据，不能拿它与五任务BCE模型比较后将差异归因于损失；两种训练覆盖在表中分开注明。
- 不强制增加fresh初始化、非锚定网络、原critic未适配、不同PCA等额外矩阵。只有将这些因素单独列为方法贡献，才需要对应对照。

报告每种损失驱动新生成动作后的成功率和相对R增益；离线误差可以帮助调试，不另设一套论文主指标。

若论文只主张两个附加项作为整体有效，L00/L11已回答最小问题；当前两个项都在方法公式中，因此保留四格用于直接组件归因。它不需要在每个H、每个模型、每个环境重复。

**删除局部采集创新对应实验：**不比较局部探针与普通rollout的等预算采集，不重采独立随机后缀证明方差优势，不做候选数量曲线。配对状态和后缀仍用于降低评估噪声，是实验控制手段。

## 4. E4＋E9：首先安排MetaWorld＋π0.5的H扫描

### 4.1 为什么应该放到开篇

H决定一次生成后连续执行多少步，改变观测反馈频率、动作过时程度及报警机会。既然本方法针对执行中的纠偏，在不同H下比较完整系统与原始策略，能直接展示适用范围；无需额外声称数据效率或推理效率。

该实验取H={10,20,30,40,50}。H=10预先固定为后续详细消融的主协议，不根据测试曲线挑最有利的H。开篇展示H曲线与首先执行协议核验不冲突：冻结模型和规则后，H扫描是第一组正式效果实验。

### 4.2 最小矩阵：16个配置单元

| H | N：普通VLA | Full-Post | Full-Velocity | R：仅报警后普通重规划 |
|---:|---|---|---|---|
| 10 | 是 | 是 | 是 | 是 |
| 20 | 是 | 是 | 是 | 不默认增加 |
| 30 | 是 | 是 | 是 | 不默认增加 |
| 40 | 是 | 是 | 是 | 不默认增加 |
| 50 | 是 | 是 | 是 | 不默认增加 |

N仍在每H步自然重规划，只是不增加报警干预。“Full”是D/G0触发加预先固定的Post或Velocity；不按每个任务、每个H的结果事后选更好的分支。

- 五个H上的Full−N支持完整系统效果。
- H=10上的R−N说明中断重规划收益；Full−R说明额外纠偏收益。
- 因而H=10四臂已经包含原“三阶段消融”，不另外建立一套重复实验。
- 如果论文要进一步写“纠偏相对重规划在所有H都有增益”，才给其余四个H加R，总计20个单元。未加R时不作该归因。

### 4.3 H与纠偏窗口C必须区分

当前critic看前10×4维动作，纠偏也只改前10步。因此本轮固定：

| 项目 | 规定 |
|---|---|
| π0.5生成长度 | 50 |
| 正常执行长度H | 扫10/20/30/40/50 |
| 纠偏承诺C | 固定10 |
| 监测间隔 | 5 |
| 干预次数 | 每episode最多一次 |
| 总控制预算 | 从初态算300步 |
| D/G0/Q及修复设置 | MT50适配与开发完成后固定，不每个H重新训练或择优调参 |

H>10时，Full在报警后执行纠偏的10步，到cut+10重新采样并恢复正常nativeH；R若存在也遵循同一规则。不能永久转为native10，也不能在10步结束后继续执行新a0未被纠正的尾部，再把结果解释为同一种协议。

Q10的训练目标是“候选执行10步后native10续跑”；H>10时后续策略和到达状态发生变化。使用固定Q10仍可检验实际系统效果，但不能把其输出当作nativeH下已校准成功概率，也不表示每个H的最优适配结果。无需为这一效果曲线预设五套Q_H训练。

### 4.4 评测与图表

- 各H使用同一批初始物理状态；每个H生成自己的正常轨迹和合法cut，不能复用H=10的cut代表其他H。
- 同一H的R/P/V共享报警cut、无引导a0初始噪声和后缀身份。跨H仅在初态层面配对，不宣称中途同状态。
- 无报警、早成功保留全体分母；技术失败单列，不能当任务失败静默填零。
- 主图：H—任务成功率，N/P/V三条线及区间。
- 配套表：各H的Full−N；H=10另列R及Full−R。
- 顺带记录每episode真实采样次数和报警率，帮助解释曲线；success-per-call、最优Pareto和节省计算比例不作为必需主张。

## 5. E3：精简相关方法比较

不同H、跨模型都比Baseline，能证明有效，但不能单独支持相对于已有纠偏工作的增量。因此保留一个直接相关的完整系统比较，优先VLA-Corrector。

建议只在MetaWorld＋π0.5、预定H=10进行同协议的代表比较，使用同一底座checkpoint、任务清单、初态和总步数。原方法的模型、数据、训练和干预机制按忠实版本说明；不同机制正是完整系统比较的内容，不为追求同cut随意改写对方方法。

其报告数据可用于相关工作表，见[公开结果汇总](../../references/vla_guidance/REPORTED_RESULTS_20260919.md)；由于任务/权重/协议不同，不能直接与本项目成功率拼成优越性榜单。缺少对应checkpoint时，先核实迁移成本，再决定实际比较范围；不能将一个简化适配伪称原方法完整复现。

当前不要求同时复现QGF、QPILOTS、GAF，更不默认增加GradStep-1/3、Best-of-2/4、局部随机搜索全家族。Post若与某个标准GradStep在坐标和投影后数学等价，直接说明；创新由训练目标承担，不制造重复名称的算法对照。

若仅能完成Baseline和E1而没有忠实外部比较，可以报告有效性和内部归因，但应收窄“优于已有纠偏方法”的结论。外部最相关对照仍是有竞争力的方法论文的重要证据。

## 8. E6：收益触发与异常触发的最小对照

用户已确认保留此创新。不把“用了G0”直接解释为“G0优于异常触发”，本节仅做以下对照：

- 同一五任务消融集、π0.5、H=10，收益触发G0与一个明确实现的视觉异常触发器；
- 下游统一普通重规划R，以分离“何时干预”与“怎样纠偏”；
- 各自阈值仅在开发集选择，尽量匹配开发干预预算；测试实际触发率照实报告；
- 按共同初态比较终局成功率。触发器不同意味着cut可能不同，不强求同cut。

现有D预测的是旧队列对应的未来变化，视觉异常触发器需在后续观测到达时计算误差；不能把当前G0分数换一个名字当成异常分数。若资产不足以做忠实视觉监测器，应先缩小/调整触发创新表述，不临时构造弱对手。

不增加定时、随机、失败风险、G10、新D架构及所有触发×纠偏交叉。旧G0存在5步标签/10步执行差异，不能新增“收益预测已校准”的主张。该最小对照支持五任务、H=10及固定下游R条件下的触发策略结论，不自动外推为所有任务、所有H和纠偏器上的优越性。

删除独立机制矩阵后，相应主张也不写进摘要或结论。例如只展示动作有界，不声称证明了约束提高安全性；只展示Full提升成功率，不声称已经证明梯度比任何同幅随机方向更优。若未来把这些主张重新加入论文，再为具体主张补唯一必要对照。

## 10. 实施顺序与统计底线

1. E0：锁定主张、MetaWorld任务范围、checkpoint、H/C语义、数据清单及可复用资产；只做文档和接口核查。
2. 开发：有限选参、MT50所需适配和E1训练。五任务原型可沿用A4000准备协议核验，但不替代50任务主模型的适配清单。H扫描不强制等待全部消融完成，新学习版本不得用新测试结果选模。
3. 第一组正式效果：E4的H曲线及H=10组件分解。
4. 在对应独立源上完成E1真实动作评测及E6；E3代表性外部对照可共用主设置N/R记录，前提是模型、数据和协议身份一致。
5. E8多模型MetaWorld与π0.5/LIBERO；E5计时和日志统计并行汇总，不复制全部消融。

同一身份的模型、任务、初态、噪声及后缀可以复用结果。不同H的cut、不同模型的轨迹、不同训练seed的生成动作不能为了省实验混成同一条记录。

旧train600可复用；已揭晓held只作历史或开发依据。新测试集在方法、任务、H、统计与seed规则固定后评估。不挑测试赢家、不因无报警或失败换源。

主要报告成功率、配对差和置信区间。按任务内独立物理初态成组重采样，后缀和训练seed随源保留；多个后缀不是多个独立初态。五任务消融的任务宏平均与完整MT50宏平均分开。

H=10的P−R、V−R、E1两个算子的Full−BCE以及E6收益触发−异常触发，是需要预先明确的核心比较；若均作为共同确认主张，应统一进行多重比较控制。其余H曲线和跨设置的逐项显著性若写成确认主张，也纳入事先规定的检验范围；不按结果挑显著H。统计要求属于可信评估，不额外生成无关实验。

新样本数按当前实际主比较、任务覆盖和可用预算规划。旧“五任务、400源、两比较”的功效估算不自动适用于MT50、全部H和新损失比较。旧参数专项的48万更新和1.68万/3.6万attempt预算已退出当前方案，不继续作为执行指标。

执行端交付逐源结局、方法/模型版本、任务与初态身份、H/C、cut、训练及后缀seed、真实调用次数、时延、技术失败与资源回执。分析端读取表格和报告，不需要大范围阅读实现代码。
