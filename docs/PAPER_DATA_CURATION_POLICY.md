# 实验总表与论文数据文档的定位

生效：2026-09-23，依据用户最新明确要求。后续整理、自动导出和人工补录均遵循本文件。

## 1. EXPERIMENT_RESULTS_MASTER.md：完整实验记录

[实验数据总表](EXPERIMENT_RESULTS_MASTER.md)记录所有实验过程中产生的数据。包括不同损失、权重、fit、触发次数、任务／底座、开发／测试划分、已完成与部分完成结果，以及原始技术失败、缺项和日志恢复结果。旧版本不能因最终论文换配置而删除、覆盖或重新标记。

总表保留结果身份、分母、数据来源和状态；新增有效终局追加至相应版本，汇总时去除同一科学单元的重复引用。技术失败不是任务失败，未取得结果不是零成功率，未运行不是零成本。历史已填写表不以新配置数据覆写；适当归档与排序可以改善阅读，但索引和证据须保持可追溯。

## 2. EXPERIMENT_FOR_PAPER.md：最终论文有效数据

[论文数据文档](EXPERIMENT_FOR_PAPER.md)只筛选最终能够进入本篇论文的有效结果，并区分正文与附录。它不是完整实验日志、任务队列、预计成绩表或作者讨论记录。

- 当前最终方法为Post-multi，完整Q训练的L11＝BCE＋gain＋0.5pair，固定fit9101。Velocity结果保存在总表及另文文档；LIBERO暂不进入本文件。
- 依赖方法配置的结果必须来自对应配置的实际终局。换Q后，成功率、调用、干预、配对区间、逐任务差值和外部方法差值一起更新；不把L01数据更名为L11。
- N、R、外部方法基线及Q无关的E6／R随机单次对照可复用。网络结构未变时可复用参数量；运行成本和性能不由参数量推定。
- 每个数值表应有明确分母、协议、结果身份和来源。部分可复用基线可以先保留；尚未完成的最终Post条目放简短待入表清单，不铺满空数值表，不写预期成绩。
- 不把开发／选型结果表述为独立盲测；不把均值差描述为已证明的普遍优势。完整披露对论文核心机制不利但有效的对照结果。

## 3. 当前L11选型与样本重叠

用户现已决定用Post三fit消融的平均成功率优先、并列时样本SD较小作为最终选择依据。L00与L11均为72.00%，样本SD分别3.46与2.00个百分点，因此采用L11；部署fit9101固定，不据测试表现再选seed。

这50个已揭晓消融初态参与了最终选型，并与原MT50主表500初态重叠。论文须披露这一事实，不能继续称它们是独立盲测，也不能把3fit×50条当作150个独立初态。该要求不引入新数据采集，不要求重跑已完成的同配置有效源。过去按开发集选择L01的原始锁和结果作为历史保留，不覆盖或伪造。

## 4. 文档更新顺序

1. 执行端写真实结果与终局状态，保留原失败和缺项。
2. 总表按实验配置归档全部新增数据；已完成有效单元不重复计数。
3. 论文文档从总表／原终局来源筛选最终配置的有效数据，补正文主表与附录。
4. 依赖这些结果的配对统计、调用成本、图表与论文文字使用同一版本；正文优势不沿用被替换配置的数字。

任务分配、并发、恢复与启动指令留在分析／调度目录。作者讨论和历史论文取表草稿可单独归档，不混入最终论文有效数据。
