# 固定 v3 评价器的 Flow Guidance 机制实验

2026-09-16。本文在新开发源采集前编写；正式封存身份见 `outputs/act_recap_ogg_flow_20260916/formal_freeze.json`。执行依据为本日 Flow Guidance 任务书。本文不是实验结果。

## 目标与不变量

检验当前评价器局部导数是否有真实方向性，以及相同实际动作变化下，梯度进入 flow 的方式是否影响收益。固定四个 v3 critic（1041–1044、每成员7058参数）、原 VLA、D、G0；不训练、不增加恢复原语、不改变后缀。

评分为四成员平均相对成功概率 `R(a)=mean(sigmoid(C(s,a;a0))-sigmoid(C(s,a0;a0)))`。状态与指定 a0 固定，actions 第0槽始终是 detached a0，第1槽才是候选。CPU两线程、单源状态投影沿用 v3 数值路径；参数和缓冲区冻结，允许动作梯度。新两槽与旧九槽的 GEMM 舍入差在可复现只读核查中最大约2.98e-7，不视为模型变化。

采样时间 τ 从1降至0、十次 Euler、步长−.1。两方法均使用 `u=x−τv`、同一反归一化和真实 clamp 导数，只在τ=.3/.2/.1引导：

- velocity：`v'=v−ατ∇uR(T(u))`，代码实际对velocity叶变量求导。
- direct：`v'=v−α∇uR(T(u))`，是 QGF 式注入适配。

两者原生强度固定α=10；无逐步回缩。QGF官方在裁剪后的干净点重新建求导变量，本实验保留真实clamp链式导数以隔离注入公式，因此不称完整复现QGF。文献核对见 `docs/ogg_flow_20260916/method_review.md`。

## 数据、候选与预算

五任务各六个新开发源，共30；环境种子2026104000–2026104029按任务轮转。预检五源2026103900–2026103904。登记时扫描历史输出JSON去重。使用现有首次G0报警、阈值.05、每五步检查、源VLA执行50步块。未报警或提前成功的源保留全部30源分母，共同结局广播所有方法。

每源固定同一次a0和相同初始flow噪声。八臂为：a0、投影后velocity、投影后direct、终点动作梯度修正、投影后direct的反向、结构化随机、未投影velocity、未投影direct。最后两臂只用于原生响应诊断，幅度不同，不能用于证明注入方式的优劣。

所有臂执行十步前缀，随后清空队列接冻结fixed10至总预算300。成功或终止时提前结束；不足十步剩余预算统一截短、单列报告。每候选8次后缀重复，种子按源、切点、重复号、后缀采样决策序号配对。动作预先生成并封存，之后才读取分支结局。

正式最多30×8×8=1920条，预检5×8×2=80条，并发复现32条；另保守计入35次源捕获，共2067次。每次开始模拟即向加锁预算账本登记，失败和重复尝试也计数；硬上限3000。剩余预算供必要实现修复，不用于按结局搜索。单步Jacobian诊断本轮不启用。

## 最终环境命令的共同幅度

仅使用前10×4实际命令，不看结局。XYZ目标RMS=.05、逐坐标上限.15；夹爪目标RMS=.10、上限.4。共同可行坐标为 `1−|a0|>=.05`，其余坐标所有投影臂固定a0。

velocity/direct方向为各自采样完成并裁剪后的命令减a0。终点方向为 `S²∇aR(a0)`，其中 `S=(q99−q01)/2`，与内部干净变量的欧氏梯度对应；这不是裸环境坐标梯度。随机方向为每维三个独立高斯结点的线性插值。反向严格取direct负方向。

各方向先在XYZ/夹爪组内归一为单位RMS，再取所有方向共同可行半径与预设目标的最小值，留1e-6相对余量。任一方向某组零范数，该组所有匹配臂回退a0；不删除该源。可能放大原生小位移，因此明确命名“投影后”；原生两臂另行执行。最终float32命令RMS误差须小于1e-6，正反和须等于2a0（同容差）；分别报告实际RMS/L∞、掩码比例、回缩和零组比例。

## 统计与解释

六个预定比较：direct−a0、direct−velocity、post−a0、direct−post、direct−reverse、direct−random。报告全30源平均配对成功率差、按任务分层的10000次源bootstrap95%区间（seed29015），以及救回、损害、完整分母和任务分层。重复后缀保留在源内，不充当独立样本。区间为名义区间，未做多重比较调整。

终点修正有效、flow无效才支持优先调查注入链路；正向未胜反向/随机，不能称评分导数具备真实方向性。Q上升而真实成功不改善，归为评分目标/局部导数未获支持。开发集最好成绩不能称独立验证成功。若出现正收益，后续须冻结候选，在新保留源确认。

旧v3六次lift误选、a0低估和共同偏差只作解释性只读诊断，不选本轮参数。全部旧封存文件与权重保留。

CPU命令需 `PYTHONPATH=src`，使用工作区lerobot Python环境。
