## 十步新评价器与独立保留验证

第一阶段按原门槛选择十步后，另行封存了[学习、校准与验证方案](ACT_RECAP_OGG_V3_LEARNING_PROTOCOL_20260916.md)。训练使用 50 个 pilot 源加 50 个新源；校准与最终验证各为另外 50 个未使用的源。50 个 pilot 是已经观察过的开发数据，最终证据单独来自新保留验证。

新模型直接读取完整十步候选和 a0。每成员 7,058 参数、四成员、不作源 bootstrap；训练折拟合后冻结的视觉/语言 PCA 为 16/8 维。保留相对概率收益损失及零残差锚定，使用信息性源 4 倍采样。所有候选均参与训练，包括有害候选和全失败源。

评价器预测的是后续继续执行冻结 VLA 后的最终成功概率及相对 a0 的增益。这里的 MSE 是这个成功率增益的预测误差，不是 D 的视觉特征预测误差；本轮 D/G0 继续用于原报警流程，没有重新训练。

训练采用 80/20 个预定源内部划分选择停止点，再重拟合全部训练源。校准只决定是否接受已经固定的原始赢家，不能根据同源结局改选第二候选。模型和接受规则全部冻结后，才采集最终验证源。

训练前的检查发现批量 PCA 缓存与单源推理在近零主成分上有约 1.04e−4 的数值差异，四成员均在第一个优化步骤前停止。修订后训练缓存统一走单源推理路径；99 个实际训练源逐位一致，未改变投影拟合范围、模型、数据划分或超参数。原失败记录和[实现修订](outputs/act_recap_ogg_research_v3_20260916/learning/training_implementation_amendment.json)均保留。

校准采集前，另将评价器推理固定为训练使用的两 CPU 线程，评分结束恢复仿真调用方的四线程设置；消除了近零投影在线程数变化下的数值差异。99 个训练源的四成员九候选概率与拟合记录逐位一致，模型权重未变。见[推理执行修订](outputs/act_recap_ogg_research_v3_20260916/learning/inference_implementation_amendment.json)。

最终训练到达源数 99/100；内部选出的停止点为 800 步。内部各检查点的集成收益 MSE 为 `[0.21296526392758547, 0.17223242935971203, 0.171208482693486, 0.17012755326658544, 0.19140235367616967, 0.23344780110282268, 0.2494189669971894]`，零收益参照为 0.23653。该选择仍属于开发阶段。

十步全银行与旧五步局部银行的标签差异和分母不同，不能直接横比 MSE 数值；应分别与本数据上的零收益预测基线比较。

校准集选择净收益 +5.25 [-0.50, +12.25] 个百分点；该数据用于选择接受规则，不能视为独立验证。原始赢家实际增益非零的源有 11 个；冻结规则为 `{"scale": 0.15518042704859472, "kappa": 1.0, "margin": 0.0, "disabled": false}`。

scale 只缩放预测增益，不缩小执行动作。当前 scale>0、κ=1、margin=0，因此实际接受条件等价于“原始赢家的平均预测增益大于四成员增益标准差”；其余退回 a0。

校准集被接受动作的平均原始预测增益为 +11.01 个百分点，乘 scale 后为 +1.71，实际平均为 +6.40。这些是接受子集上的条件均值，不等于完整 50 源的净收益。

## 失败定位与下一步

**本轮建议继续采用仅重规划 a0。** 开发银行的潜力明显扩大，校准集也出现 +5.25，但当前冻结策略没有在新保留源上达到约 +5，不能据开发点估计认定有效。实验模型和策略保留用于复现。

验证的配对后缀救回为 +4.00 个百分点，损害为 −10.00，净 −6.00。按实际选中的方法分解如下；这些分组已使用验证结局，只用于解释失败。

| 被选动作 | 源数 | 正 / 负净收益源 | 救回 / 损害次数 | 对完整 50 源的净贡献（百分点） |
| --- | --- | --- | --- | --- |
| gripper_minus | 11 | 0 / 2 | 2 / 6 | -1.00 |
| gripper_plus | 16 | 1 / 0 | 2 / 1 | +0.25 |
| replan | 7 | 0 / 0 | 0 / 0 | +0.00 |
| backoff_reapproach | 9 | 3 / 1 | 12 / 2 | +2.50 |
| lift_return_regrasp | 6 | 0 / 6 | 0 / 31 | -7.75 |
| xyz_minus | 1 | 0 / 0 | 0 / 0 | +0.00 |

六次 `lift_return_regrasp` 全部为负净收益，造成 31/40 次损害。两个 shelf 源 `2026103162`、`2026103182` 中，a0 均为 8/8 成功，所选 lift 均为 0/8；同源已执行的 backoff 均为 8/8。这里可以确认该原语在这些状态下造成损害，具体接触/抓取机制尚需物理轨迹诊断。

即使事后将这六次选择直接置回 a0，机械计算也只有 +1.75 个百分点。这个事后规则不算新验证，也不等同于移除候选后重新排序；仅禁用最坏原语仍不足以证明 +5。

最终验证只执行了 a0、固定模型原始赢家、固定 backoff 三臂，因此没有完整九候选的验证上限。在这三臂上事后做 4+4 真实结局交叉选择，潜力为 +5.00 [+1.25, +9.50]，八次事后最优为 +7.00 个百分点。这仍是使用真实结局的诊断，不能记为算法成功。

下一轮优先顺序：

1. 给高干扰恢复原语增加状态适用性建模。优先检查抬升、开夹、重抓在当前抓取/接触阶段是否成立；部署判定使用当前视觉、本体和动作历史。仿真接触真值可用于开发教师或诊断，不能直接作为视觉部署输入。先在新的开发源核验原语的救回与损害。

2. 在训练源内部按完整源分折，直接检验赢家排序、救回与损害，并与当前按全候选 MSE 早停作对照。平均 MSE 降低主要说明部分动作收益更可预测，不能保证最优候选被选对。新报警源上的特权状态参照可用于区分视觉表示与排序问题；旧固定切点参照不能替代这项诊断。

3. 校准集只有 11 个原始赢家净收益非零的源，规则稳定性仍不足。增加独立、有动作响应差异的开发/校准源，保留有害和无收益源；用新源冻结拒绝机制，再安排新的完整保留验证。当前验证源已经曝光，后续只能作开发诊断。

本轮不支持继续仅靠增加数值幅度或把已曝光任务分组直接写成部署规则。梯度引导及 D 分支升级仍需等待有限候选策略在新的保留源上形成可靠净收益。
