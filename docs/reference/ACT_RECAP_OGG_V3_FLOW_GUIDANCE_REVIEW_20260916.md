# OGG v3 失败分析与 Flow Matching 引导研究建议

日期：2026-09-16。审阅对象是最新 [v3 结果](ACT_RECAP_OGG_V3_RESULTS_20260916.md)，并重新核对旧 OGG 梯度实现。文献已联网查看原论文及可用的官方代码。本次只做 CPU 复核与研究设计，没有训练或执行新的机器人分支。

## 1. 结论需要随 v3 更新

**v3 的主要证据已从“候选缺少改善空间”转向“评价器无法在新状态下可靠选择恢复动作，且拒绝机制挡不住共同误判”。** 新恢复候选在开发集展现较大潜力，但最终冻结策略仍把原本能成功的状态改坏。

同时，**v3 最终策略是离散候选选择，没有执行新的 flow matching 梯度引导**。它不能证明 QGF、QPILOTS 或新的采样公式已经失败。建议并行推进状态条件评价与受控的 flow sampler 对照。

### 1.1 最新结果

| 项目 | 结果 |
| --- | --- |
| 50 个新保留源，a0 执行十步 | 60.00% |
| 冻结纠偏策略 | 54.00% |
| 配对收益，95% 源 bootstrap 区间 | −6.00 [−13.75, +1.25] 个百分点 |
| 接受纠偏 | 43/50 源 |
| 配对后缀救回 / 损害 | 16 / 40，贡献 +4 / −10 个百分点 |
| 开发集十步合并银行 4+4 交叉选择潜力 | +29.50 [19.00, 40.50] 个百分点 |

开发集潜力使用真实结局选择候选，是诊断而非可部署策略。最终验证只执行 a0、模型原始赢家、固定 backoff 三臂，没有完整九候选验证银行；这三臂事后交叉选择约 +5 点，同样不能记为算法成绩。

### 1.2 六次抬升重抓解释了大部分损害

六个被选中 `lift_return_regrasp` 的验证源全部负净收益，造成 31/40 次配对损害。复算四成员概率得到：

| 这六个源的条件均值 | 模型预测 | 八次配对后缀经验结果 |
| --- | ---: | ---: |
| a0 成功率 | 21.58% | 81.25% |
| lift 成功率 | 36.64% | 16.67% |
| lift 相对收益 | +15.06 个百分点 | −64.58 个百分点 |

模型把原本大多能成功的状态判断成低成功率，再认为抬升重抓可以改善。`shelf-place-v3__2026103162` 和 `2026103182` 中，a0 与已执行的 backoff 均为 8/8，所选 lift 为 0/8；四成员却全部预测 lift 有正收益。

训练并非缺少这个原语的负例：99 个实际训练源中，lift 有 9 个正收益源、51 个负收益源、39 个零收益源，平均相对收益 −33.21 点。**更准确的问题是缺乏可泛化的状态适用性判断。** 六源切片是事后诊断，尚不能把每次损害都解释为开夹掉物；物理接触原因需要进一步检查。

原语 [candidates.py](src/ac_tmil/ogg_research_v3/candidates.py) 实际执行开夹上移、开夹下移、原地闭夹，这与一般平滑微调存在明显区别。扩充恢复动作同时扩大了可救回空间与误用损害，选择器因此承担更高的判断要求。

### 1.3 小模型、早停、集成和校准分别解决了什么

- v3 已采用每成员 7,058 参数、训练折内 PCA、早停及信息性源重采样。继续只建议“缩小模型、加入相对损失”会重复已有工作。
- 早停选择的是所有候选的平均相对收益 MSE。它与赢家的真实净收益、损害风险不同；但不能据此认定换一个停止点就能修复本次泛化失败。
- 四成员共享数据、表示、结构与训练目标，标准差衡量分歧，不能发现共同偏差。两个 shelf 例子直接展示了这一点。
- 冻结规则为 `scale=.15518, kappa=1, margin=0`，接受条件是 `scale*(mean_gain-std_gain)>0`。正的 scale 在这里抵消，不改变接受决定，也不缩小动作；最终实际相当于 `mean_gain>std_gain`。
- 校准最高预测分箱的平均真实收益已为负，说明仅做一个正比例缩放不能修复排序。具体分箱样本少，不据此重新调已曝光策略。

复核：[脚本](analysis/ogg_v3_flow_review_20260916.py)、[指标及输入 SHA](analysis/ogg_v3_flow_review_20260916/metrics.json)。

## 2. 当前到底测过哪种 Flow Matching 引导

最新 `FrozenSelector.score` 在 [learning.py](src/ac_tmil/ogg_research_v3/learning.py) 中使用 `@torch.no_grad()`，对九个现成候选评分并选择，没有优化动作、噪声或 flow velocity。

历史梯度实现位于 [ogg/core.py](src/ac_tmil/ogg/core.py)。它冻结并 detach VLA 速度输出，把速度作为新的叶变量，对动作目标求梯度。这里只能分析该旧实现，不能把它的局限直接认定为 v3 负收益的原因。

### 2.1 时间参数化：当前 1→0 与论文常用 0→1 相反

设当前噪声时间为 τ，从 1 降至 0；内部动作变量为 x，VLA 输出为 v；T 表示反归一化及裁剪。干净动作估计为：

\[
u=x_\tau-\tau v,\qquad a=T(u).
\]

令 \(\widetilde L(u)=L(T(u))\)。现有代码执行：

\[
\nabla_v\widetilde L=-\tau\nabla_u\widetilde L,
\quad v'=v-\alpha\nabla_v\widetilde L
=v+\alpha\tau\nabla_u\widetilde L.
\]

因此，固定当前 x 时，新的单步干净估计满足：

\[
u'-u=-\alpha\tau^2\nabla_u\widetilde L.
\]

而采样器实际 Euler 步 \(\Delta\tau=-h\) 的额外变化是：

\[
\Delta x_{\rm extra}=-h\alpha\tau\nabla_u\widetilde L.
\]

这两项不能混淆：前者是干净估计变化，后者是当前积分状态变化，最终动作还受后续采样影响。历史只在 τ=.3/.2/.1 引导，参数化额外带入 τ 缩放；这不是自动成立的符号错误，也不是已证实的失败主因。

### 2.2 还需要区分的几个实现因素

1. **梯度目标。** 当前旧 C 引导的损失与 Q 的概率、log 概率、logit 不同。v3 训练使用 sigmoid 概率差监督，但若未来选择 logit 梯度，引导尺度与含义需要重新定义。
2. **动作单位。** 对内部归一化变量、环境命令、平移和夹爪求梯度，尺度不同。T 的导数与维度权重必须显式记录。
3. **裁剪。** 当前 T 的 clamp 在越界区间会切断梯度。QGF 官方实现在裁剪后的干净点重新建立求导变量，行为不同；这项差异值得测量，不应未经验证就用 straight-through 替换真实导数。
4. **一步估计与实际终点。** 在中间 flow time 得到的 u，不等于剩余采样完成后的实际动作。尤其早期，多模态动作的均值可能不是有效策略。不能把 u 的评分改善当作最终动作改善。
5. **最终约束。** 旧代码约束当步干净估计变化，未形成相对同噪声 a0 的最终动作硬约束。不同梯度公式须比较最终执行命令改变量。
6. **执行窗口。** 旧 hook 硬编码前 5×4，v3 critic 读取 10×4。以后迁移时必须统一前缀、评价器与 fixed10 后缀，不能直接接上后把差异归因于 sampler。

## 3. 网上方法中最值得借鉴的几条路线

### A. QGF / GAF：干净动作梯度直接修正速度场

QGF 在一步干净估计上评价 Q，采用单位 Jacobian 近似，不反传 VLA。GAF 将相似方式用于冻结 VLA，并加入梯度限制和集成门控。[QGF 论文](https://arxiv.org/html/2606.11087v1)、[GAF 论文](https://arxiv.org/html/2607.02092v1)。

转换为本项目的反向时间，令 \(R(u)\) 为已包含动作变换的最大化目标，直接形式是：

\[
g=\nabla_uR(u),\qquad v'=v-\lambda(\tau)g.
\]

与当前形式相比，它不因“对 v 求导”而额外带入 τ。这里的转换是依据本地代码的推导，不能把论文正向时间的加号直接复制过来。

**优先级最高：**作为低成本、可解释的 sampler 基线。必须与原参数化匹配最终动作幅度，以区分方向、时间分配与单纯增强扰动。QGF 官方代码还提供 Jacobian 开关及明确的 stop-gradient 路径：[核心实现](https://github.com/zhouzypaul/qgf/blob/main/agents/qgf.py)。GAF 的锁定测试仅从 26/40 到 27/40，也提醒我们不能将其作为小样本评价器泛化已经解决的证据。[GAF 官方实现](https://github.com/ylhaichen/guided-action-flow)。

### B. QPILOTS-U：保留单步去噪映射的 Jacobian

QPILOTS-U 对噪声变量求干净估计价值的导数；实践中使用梯度尺度控制。QPILOTS-M 则增加条件后验模型，并非简单多采几个独立 VLA 动作。论文在 LIBERO 中使用每任务 50 万环境步学习 critic，数据条件与本项目差异很大。[QPILOTS 论文](https://arxiv.org/html/2606.14801v1)。

按本地约定，单步映射为：

\[
J_\tau=I-\tau\frac{\partial v_\theta}{\partial x_\tau},
\qquad g=J_\tau^\top\nabla_uR(u).
\]

**适合作为对照，不能预设更好。** 它可能恢复有用的动作耦合，也可能放大噪声与错误梯度。QGF 原论文反而观察到忽略 Jacobian 在其设置更稳，因此值得比较两个选择，而不是默认更完整的导数更正确。[QGF 的 Jacobian 分析](https://arxiv.org/html/2606.11087v1)。

可追加一个本项目工程假设：使用 \(g_\rho=(1-\rho)g+\rho J_\tau^\top g\) 做向单位映射收缩的少量预设对照。此处的具体混合方案不是声称复现 QPILOTS 原算法。VLA 权重仍冻结，但这条路径需要允许对动作输入反传。

### C. On the Guidance of Flow Matching：分布约束与无导数引导

这篇 ICML 2025 工作统一讨论一般 flow guidance，给出协方差预条件的局部梯度，以及基于采样的无导数估计。对线性噪声→数据路径，其局部思路包含条件终点协方差，而不只是欧氏空间的裸梯度。[论文](https://arxiv.org/html/2502.02150v3)、[官方代码](https://github.com/AI4Science-WestlakeU/flow_guidance)。

**对本项目最有价值的两个研究问题：**

- 能否把纠偏限制在 VLA 支持的、时间协调的动作变化方向，减少对原计划的大幅破坏？
- 如果 Q 的离散数值尚可，但局部导数不可靠，有限差分或无导数采样是否更稳？

可以先在低维平滑动作空间，用同半径正负扰动估计方向；也可用 VLA 候选的经验低秩协方差作预条件。这些是工程近似：\(\operatorname{Cov}(a\mid s)\) 不等于论文需要的 \(\operatorname{Cov}(a_1\mid x_t,s)\)，普通重采样也不等于条件后验采样，不能声称复现其渐近精确保证。

无导数方法仍依赖正确评分。若模型将 lift 整体评错，去掉导数同样会选错。夹爪开合或不同绕障模式也不宜直接求动作加权均值；优先比较实际采样候选选择或局部单模式修正。

### D. D-Flow：完整生成链反传，作为小规模机制诊断

D-Flow 冻结生成器，通过完整 flow 映射反传终点损失并优化初始噪声，主要验证于图像、音频和分子任务。[正式论文](https://proceedings.mlr.press/v235/ben-hamu24a.html)。

它适合检查：一步干净估计或单位 Jacobian 是否漏掉必要的生成耦合。当前 VLA 采样只有十步，可以先评估少量源的全链或尾部反传成本；尾部版本是本项目拟议近似。完整反传只提高对给定评分器的求导完整性，不保证更高真实成功率，也不保证噪声优化后仍精确服从原动作分布。

### E. RTC / FBFM：用可核实反馈构造引导目标

RTC 将已承诺执行的重叠动作作为 inpainting 条件，以处理异步执行连续性；FBFM 进一步将真实观测反馈约束到世界动作模型对应的状态槽位。[RTC 原论文及项目](https://www.pi.website/research/real_time_chunking)、[FBFM 论文](https://arxiv.org/html/2607.29235v1)。

这里的启发是给引导一个可验证目标，而不是完全依赖长期成功率评价器。适合处理已执行动作一致性、延迟和观测对齐。当前 π0.5 动作生成器不等同于联合生成未来状态与动作的 WAM，FBFM 不能直接移植；本项目的辅助 D 也尚未提供可靠的状态到动作导数。不能强迫未来状态等于旧观测，或把追赶旧预测自动解释为恢复任务。

补充参考 [VGG-Flow](https://arxiv.org/html/2512.05116v2) 研究通过价值梯度匹配微调 flow；[πR²](https://arxiv.org/abs/2607.26055) 通过快慢观测通道和去噪调度提高闭环频率。两者涉及训练方案变化，可作为长期方向，当前优先级低于上述可隔离的推理对照。

## 4. 为什么现有 C 即便拟合候选，也未必适合连续梯度

每源十步动作有 40 个坐标，训练只观测 a0 加八个候选的结局。有限离散点上的拟合，不能唯一约束这些点周围的导数。当前有相对概率损失和零点锚定，但这些性质都不保证沿梯度走一小步会更好。

因此需要把“候选排序能力”与“邻域梯度能力”分别验证。可以用新开发源，在 a0 周围按预定小半径采集正梯度、反梯度和多个匹配随机方向，保留真实 fixed10 后缀；用配对结局检验方向。若要监督局部导数，应使用这些真实分支的有限差异，并保留不确定性；接触不光滑处不要强行假设存在稳定微分。

还有一个分布问题：flow 中间的干净估计未必落在九候选覆盖区间。应记录每个时间点估计相对最终 a0、相对训练命令支持的距离。对动作数值拟合好与对这些查询点可靠，是不同要求。

## 5. 推荐的下一轮实验：两条线并行

### 5.1 先拆开评价器与采样器，不再一起换所有部件

**采样器机制检查：**固定输入观测和初始噪声，先用已知梯度的动作空间目标（如距给定可行命令的平方距离）检查符号、T 的尺度、边界与最终约束。它只验证优化链路，不代表任务纠偏有效。

**真实收益检查：**使用同一个冻结评价器、同一组新开发源、同一 a0 和十步执行窗口，对比：

| 对照 | 要区分的问题 |
| --- | --- |
| a0 | 仅重规划基线 |
| 原 velocity-leaf 参数化，适配十步 | 时间缩放与现有更新 |
| QGF 式干净动作直接引导 | 单位 Jacobian 的低成本基线 |
| 在完成采样的 a0 上直接做受限梯度步 | flow 注入本身是否增加价值 |
| QPILOTS-U 式单步 Jacobian | 生成耦合是否有益 |
| 与主引导匹配的反向及随机方向 | 是否存在真实方向性 |
| 低维有限差分 / 无导数对照 | 连续导数与数值评分的差别 |

这是一组候选研究对照，不建议同时为每组搜索大量参数。先选少量预设强度，在开发源限定主比较，再用新保留源确认。

必须统一的因素：实际执行窗口、critic 目标、初始噪声、后处理、后缀策略和完整源分母。**最终命令幅度匹配**用于机制比较；额外也报告各算法在预设原生强度下的结果，避免后处理投影本身掩盖行为。计算成本、额外 VLA 调用和反传内存单独记录。

最终半径可通过开发阶段固定设置或只读取命令、不读取结局的回缩控制；不据验证成功率挑半径。最终 clipping、投影会改变方向，需要重新测量执行后的偏移，而不是只报告参数 λ。

### 5.2 同步修复“什么时候允许大幅恢复”的评价

- 把小范围 flow 微调与开夹、重抓等高干扰恢复分开检验适用条件。对后者增加抓取/接触阶段监督与拒绝能力，不直接用一个小的正 ΔQ 触发。
- 在训练源内部验证选中动作的实际损害与净收益，并报告模型将高成功率 a0 误判为低成功率的频率。平均 MSE 仍可保留为辅助指标。
- 用新开发数据检验共享表示下的集成共同错误。增加成员数或仅增大 κ，并不自动修复这种问题。
- 如扩大到 SARSA/TD critic，须明确 action chunk 时长、奖励累计、下一状态和后缀策略；不能把论文 critic 配方直接当作目前单次十步干预概率标签的等价替换。

### 5.3 结果怎样解释

- 终点动作梯度有效，而 flow 注入失效：优先修正注入时间、Jacobian、尺度和后续采样影响。
- QGF 优于原参数化且优于同半径反向/随机：支持干净梯度注入设计有效。
- 只有 Q 上升，真实结果无改善：评价目标或导数仍不可靠。
- 无导数方法有效、自动微分无效：支持局部梯度形状存在问题，但还要控制采样覆盖与预算。
- 所有评分驱动方法都损害：优先修复评价与适用状态，或研究有明确反馈约束的目标。

## 6. 优先级总结

**最近的一步：QGF 式直接干净动作梯度 + 实际命令信赖域 + 正/反/随机方向对照。** 同时定位 v3 为什么把高成功率 a0 误判为需要重抓。随后比较单步 Jacobian 与无导数方向；完整反传作为小规模机制组。当前不优先新增 QPILOTS-M 后验网络或整套 flow 微调。

这个顺序既认真检验了 flow matching 引导，也保留了对错误评价器的识别能力。理论上更精细的采样，无法自动补足“哪个恢复动作在这个状态有益”的信息。
