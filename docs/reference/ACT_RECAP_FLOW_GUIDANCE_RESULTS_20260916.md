# 固定 v3 评价器的 Flow Guidance 机制实验结果

日期：2026-09-16。

本报告由封存参数、逐源真实结局及审计自动生成。实验用途是分辨评分方向与 flow 注入机制；全部方法共用冻结 v3 critic、VLA、D、G0，没有重训。

QGF 式直接注入相对 a0 的真实配对收益为 **+5.83 [-0.83, +13.75] 个百分点**；采样后梯度修正为 **+9.17 [+1.25, +18.75] 个百分点**。以下判断同时看幅度匹配的方向对照和区间，不以 Q 是否上升代替真实收益。

终点梯度修正、反向、随机的实际成功率分别为 78.75%、57.08%、51.67%；终点修正减反向/随机的点差为 +21.67/+27.08 个百分点。这两项是描述性补充，不冒充六项预登记比较。不能因为几种引导都相对 a0 为负，就跳过这些控制并把原因判为评分方向。

评分方向：直接引导相对同幅反向、随机两项名义区间下界均大于零，支持当前直接引导产生的命令方向具有比较优势。该证据仅对应这组新开发状态、半径和随机对照分布，不证明所有连续邻域的梯度都可靠。

终点修正相对a0的区间下界为正，且点估计优于反向和随机，说明不能将问题一概归为评价器没有可用方向。由于终点与两个控制的差值这里只作描述，仍不把这种排序当成独立确认。

梯度进入 flow 的方式：终点与 flow 内方法的当前对照不能把失败单独归因于注入方式。二者共享同一个冻结评分目标；评分误差、局部导数及采样路径仍可能共同限制收益。

直接注入与原 velocity 参数化的配对区间跨零，尚未分辨出稳定差异。

达到约 +5 点开发点估计的方法为：原 velocity，最终幅度匹配、QGF 式直接注入，最终幅度匹配、采样后梯度修正，最终幅度匹配。这些是同一开发集多方法比较，不构成独立验证成功；需固定候选版本及新保留源方案后另行确认。

**本轮是开发机制筛查，开发集最好成绩不称独立验证成功。** 八次后缀是同源配对重复，独立统计单位为源。

## 参数、实际命令半径及回退

引导最大化 `R(a)=mean_i[Q_i(s,a;a0)−Q_i(s,a0;a0)]`，四成员sigmoid概率先平均；固定状态和槽0的指定a0，只对槽1候选求导。原 velocity 使用 `v'=v−alpha*tau*g`，直接使用 `v'=v−alpha*g`，alpha=10，时点=[0.3, 0.2, 0.1]。采样时间1→0、Euler步长−0.1，两组共用T与真实clamp导数。

只固定一组匹配目标：XYZ RMS≤0.05、夹爪 RMS≤0.1；Linf上限分别为0.15/0.4。共同边界mask为`1−abs(a0)>=0.05`，执行后幅度差容差1e-06。这些量是[-1,1]环境命令单位，不是米。

匹配对最终反归一化及裁剪后的前10×4命令实施，可能放大原生扰动；表中的匹配臂与原生臂因此分别命名。后采样方向为`S² grad_a R`，S为反归一化斜率；随机方向使用每维三节点平滑插值，反向是direct匹配命令差的负值。

**命令归一化的解释限制：** XYZ与夹爪分组归一化会显著放大某些很小的原生夹爪方向，并改变XYZ/夹爪的相对比例。匹配臂是带额外最终命令投影的实验对象，不能称为原生QGF性能。原生velocity/direct另列；其实际幅度不同，不能据原生臂之间的收益差直接作同幅机制归因。

**局部性的范围：** 最终命令相对a0的半径约束不约束中间干净动作估计或critic查询路径。较大alpha可以在中间更新产生明显变化，即使最后命令落在小半径内。因此本轮仅保证最终执行扰动受限，不声称整个生成链或中间评价查询都处于局部邻域；中间查询超出训练支持仍是评分可靠性的一个限制。

## 已证实的实现性质、机制证据与边界

已证实的实现性质：预检审计状态`passed`，正式审计状态`passed`；固定a0槽与状态、R(a0)=0、冻结权重SHA、同初始噪声、零强度逐位还原、真实sampler解析目标符号、无额外环境步、命令重建和float32幅度匹配均已检查。原始source物理回放容差1e-10，同候选重复前缀物理和图像逐位一致；后缀实际生成时刻和随机seed按决策序号核对。

机制支持以开头的配对比较为准。旧v3同步诊断另见[只读复核](docs/ogg_flow_20260916/legacy_diagnosis.md)：它解释旧离散选择器的lift误选、a0切片低估、四成员共同偏差及margin=0的scale抵消，不承担本轮新方法的效果验证。

尚未解决：30源规模对约+5点可能缺乏功效；评价器训练来自离散动作银行，连续局部导数未被训练标签充分约束；未对Jacobian、全链反传、更换critic、不同注入时点或第二组半径作结局驱动追加；没有真实机器人迁移证据。若本轮出现正的开发候选，下一步须先固定该版本与独立新源验证方案。

本轮为QGF式直接干净动作注入适配，保留本地T的真实clamp导数以隔离主因素；没有同时复现官方裁剪后重建求导变量的路径。推导、论文与作者代码核对见[方法审查](docs/ogg_flow_20260916/method_review.md)，其中包括[QGF官方实现](https://github.com/zhouzypaul/qgf/blob/main/agents/qgf.py)。
