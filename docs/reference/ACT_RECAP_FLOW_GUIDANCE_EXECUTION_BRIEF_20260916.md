## 3. 实现必须固定的语义

### 3.1 评价器目标与参照

- 使用 v3 四成员平均相对成功概率：`R(a)=mean_i[Q_i(s,a;a0)-Q_i(s,a0;a0)]`。本轮所有梯度方法用同一目标，不混入 logit/log概率目标。
- 固定同一状态 s 和指定 a0，仅对候选动作求导。v3 的 `actions[:,0]` 是参照 a0，优化候选必须放在其他槽；不能把候选当成新的第0槽。
- 明确保留参数冻结、允许动作输入梯度。验证同动作收益为零，修改候选不改变 a0，训练权重 SHA 不变。
- 新动作来自连续邻域，可能超出离散训练候选的支持；这正是待检验问题，不预先假定评分可靠。

### 3.2 flow 与执行约定

- 核对当前时间为 τ:1→0、Euler 步长为负，干净估计 `u=xτ−τv`。
- 令 T 为内部归一化动作到环境命令的变换，`g=∇u R(T(u))`。原参数化为 `v'=v−ατg`；直接引导为 `v'=v−λ(τ)g`。用解析目标和实际 sampler 核对符号。
- 主参数化对照采用相同动作变换、裁剪求导策略、引导时点和评分函数，只改变上述注入方式。若增加 QGF 官方的“裁剪后重新建求导变量”版本，将其作为单独命名的对照，避免同时改变多个因素。
- 原 hook 的 5×4 必须适配至评价器的 10×4。所有实验执行十步候选，然后清空队列、接 frozen fixed10 至总预算300。
- 每源复用同一次 a0、初始 flow 噪声及配对后缀随机种子；环境状态、观测和剩余预算一致。

基本对照：

1. 仅重规划 a0。
2. 原 velocity-leaf 参数化，统一适配十步。
3. QGF 式干净动作梯度直接注入。
4. 采样结束后，在 a0 上作受限的直接梯度修正。
5. 与主引导最终命令差对应的反向修正。
6. 相同命令幅度的结构化随机修正。

最终命令投影后的结果与原生算法结果应明确命名。协议写清半径度量、容差和回缩方法；报告实际达到的 XYZ/夹爪半径，避免将不同幅度混为算法优势。

### C. 解释结果

- 终点修正有效、flow 内引导无效：检查注入时间、尺度、Jacobian 与后续采样影响。
- 正向未优于同幅反向/随机：当前评分梯度没有得到方向性支持。
- 评分上升但真实收益无改善：定位评价目标/局部导数，不记为纠偏成功。
- QGF 有开发正收益：冻结候选版本及后续新保留源验证方案；本次开发结果不能称独立确认。
