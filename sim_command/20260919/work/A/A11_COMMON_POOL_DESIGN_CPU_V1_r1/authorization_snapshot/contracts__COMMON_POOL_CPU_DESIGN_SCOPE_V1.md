## 分析现在确定的设计边界

- 主公共池按π0.5＋MT50全部50任务规划，以H10为统一采集基准，生成50、Q纠偏窗口C10、后续native10。不因E4五H复制五套训练池。各任务计划父源等额；具体train/dev数量、cut数量和候选/后缀数留到报价审查后冻结，未定值不能冒充可执行额度。
- 数据/标签必须区分D5预测、G0的execute5_then_fixed10收益目标、Q的C10后续native10目标；不把旧G0悄悄改成G10，不训练五套H专用Q。窗口不同时显式标注，不把不同目标的标签互相顶替。
- 不能仅以当前五任务G0的报警决定新主池是否有某任务。提出预先固定、与结果无关的源/cut选择和覆盖机制；无合法cut、无报警、早成功/终止和技术失败保留，不能换seed凑样本。
- 新MT50公共原始池与历史五任务访问集合分名。E1继续封存train600，不为补RGB重采这600。历史索引为700 prefix＋600 a0 repeat0 suffix，缺观测/next/独立终止标记，不是完整候选库。可引用既有MT50示范及合法已有字段，缺项明确null。历史revealed-held不得回流新训练或充当新独立测试。
- 所有方法可访问同一冻结原始池，视图按本方法、VLA-Corrector、GAF-v1 adapted的真实目标分别构建。共同数据不等于全部历史训练数据一致；保留π0.5已训练于MT50示范、五任务D/G0/Q及旧LVM初始化沿革。VLA-Corrector合法正常(t,t+10) token对与Q聚合/PCA特征不可互替，必要共享提取只计一次实际成本。
- split按parent，全部cut/候选/后缀/repeat归同split；正常示范也按原episode划分，不回到旧frame-pair随机90/10。基础π0.5已见过示范的事实保留，不能把新划出的示范dev称作底座从未见过。
- complete suffix才提供对应终局监督；未知未来、技术失败和预算截尾不能变成失败标签。明确normal与a0、真实anchor/候选/后缀、raw alias去重及有效监督掩码。数据采集本身不宣称创新或数据效率。
- 恢复/回放用于局部候选可比性，需明确任务/目标、物理状态、RNG、步数/终止、策略队列/历史与噪声身份的恢复和核验边界。仅qpos/qvel、相同seed或观测前缀相同不等于完整隐藏状态证明；特权状态只用于恢复/核验，不进入策略/critic输入。提出可执行验证条件与未证明时的保守解释，由分析再决定；不要在CPU设计中宣称验证完成。
- A/B未来显式分片互斥、同parent完整归属一个owner；A汇总发布原始池manifest，分析冻结引用，B保留独立视图。不创建联合wave或绕过两端compute-exited屏障。B当前预检绑定修正未交，不影响A先做本CPU方案，但不能假定B已经可执行计算。
