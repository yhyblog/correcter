# A00/B00 盘点后的分析决定

日期：2026-09-19。依据两节点 `receipts/A/A00_REPORT.md`、`receipts/B/B00_REPORT.md`，盘点验收见 `manifests/INVENTORY_ACCEPTANCE_V1.json`。本文件补充 P00 准备合同，不放行任何 GPU 推理、训练或仿真。

## 立即执行的准备任务

A00 与 B00 均已完成；A10、B10 依赖已满足，按 `releases/P00_PREP_V1.json` 继续。B00 报告中“尚未发布 B10”的陈述已经过时，以当前 CONTROL/TASK_BOARD 和本轮 release 为准。两台均为 8×H100 80GB；模型 GPU 可运行性、仿真恢复及渲染仍需有限预检，盘点通过不能替代这些检查。

A 优先发布小型不可变接口样例，B 不等待全部核心实现再开始自己的 CPU 适配。P00 release 的 contract/task SHA 不变；CONTROL 后续增加盘点、存储或角色信息时，重新核对任务授权与范围，不把元数据 revision 的变化当作需要重跑已完成盘点的理由。

## 外部近邻与触发器选择

1. **E3 唯一 critic 引导近邻选为 GAF-v1 adapted（π0.5＋MetaWorld）。**选择依据是数据目标与 PyTorch 工程兼容性，发生在本轮测试之前。QGF 留作技术备选，不同时新增第二个 critic 基线。B10 冻结论文 v1、实际仓库 commit/文件 SHA 和适配表；不得称作 GAF-v3，也不将未证实关联的仓库称为官方实现。若关键机制无法实现，B 回报具体缺口，由分析端在测试前决定替换，不能依据测试成绩挑选方法。
2. GAF-v1 保留 discounted success-to-go、MSE、独立 critic ensemble 和原生引导机制；B10 写清首次成功时间定义、折扣单位、失败目标、实际执行动作长度与样本筛选。底座/特征/4维动作/采样接口的变化明确标作适配。不得改成当前 Q 的 BCE，或强制接入 G0 单次触发后仍冒称 GAF 原生完整系统。实际采样/引导频率交短表后冻结。
3. **E6 异常触发器选用同一 D 的因果 5 步预测误差。**在早先时刻保存预测，真实后续观测到达后计算误差；预测对应动作必须与实际连续执行动作相符，跨 reset/分支或动作不符的预测不能报警。两触发器均接 R、相同合法窗口与每 episode 一次上限，按同一初态配对，不强求相同 cut。
4. B10 准备误差定义、预热、无合法预测时的处理及开发阈值选择。保持 G0 既定开发口径，异常阈值尽量匹配开发集干预率，测试阶段不追平；明确开发匹配精度。优先复用既定开发记录，不为阈值额外开一组 rollout sweep。记录可评分窗口、动作对齐失败和实际干预率，避免将预测不可用误判为触发判断质量差异。若 D5 输入/输出语义无法支持这一因果过程，先回报，不能凭命名假定可用。

## 适用性实验底座

- **SmolVLA：使用现存 step50000 作为 E8 候选底座；不自动续训至 100k。**有限预检通过后，以同一底座做 N/P/V。声明训练历史为 50k，不称为原计划 100k 已完成，也不据此讨论底座训练效率。
- **X-VLA：保留 E8，完成训练的 MT50 权重依赖尚未满足。**B10 先准备接口、核实可用权重来源并报价最小底座训练需求；不把初始化充当已适配模型，不自动重启历史队列。确需新训练时单独发布有限任务，不阻塞 π0.5 核心工作。
- **π0.5＋LIBERO：优先现存最终 29999/30k 推理资产。**严格匹配其 normalization/processor；已删除的 optimizer 不影响推理资产可用性，不为本实验重建旧训练。四套件仍保留，本方法的跨环境特征/动作及 D/G0/Q 适配另计准备与预算。

## 公共数据与资产保留

A 的原始轨迹抽查证明已有逐步 action/reward/success/physics state；B 检查的 bank 缺少这些字段，两者并不矛盾。先建立现有真实轨迹索引；可恢复的首次成功时序直接引用。没有合法观测、next 观测或独立 termination/truncation 的记录须标缺失，不能由终局均值或特权 state 冒充。

E1 使用现存 train600 监督，不为补字段重采这 600 源。外部基线共用的新原始池在既定采集过程中一次记录必要字段。VLA-Corrector 正常动态视图可取现有示范，token latent 在预算放行后统一提取；不让各方法重复生成同一份特征。历史状态恢复渲染只有报价明确优于替代方式时才另行考虑，所有计算仍计预算。

**保留：**π0.5 MT50 SFT030000 完整推理目录、MT50 原始示范、本地 VLA-Corrector best_cosine、五任务 D/G0/Q 与 PCA、train600 及原始树、Smol50k 及实际需要的恢复资产、X-VLA 初始化/底座、LIBERO 最终推理目录和原始数据、standalone/native10 结果及依赖。这些是当前或后续已规划实验的输入，不作为“旧数据”清理。

执行端按 `STORAGE_RETENTION_V1.md` 提交其他候选。分析端逐项决定 `delete/keep/defer` 后，由执行端实施；目前尚无删除 release。无需重建已经清理且本实验不用的历史 payload。共享挂载的池级可用容量不代表项目配额，盘点报告须区分已知与未知。
