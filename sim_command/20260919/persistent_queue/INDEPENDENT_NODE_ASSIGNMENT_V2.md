# A/B 独立任务线 v2

用户2026-09-21要求两台服务器分配不同任务，A不能因B等待或故障而停止推进。本补充覆盖V1的“共同池按A/B分片”和跨机阶段依赖；与八卡利用率补充一起由`AUTHORIZATION_V2.json`发布。所有源身份、split、seed、cut、标签和方法数值保持不变，改变的是尚未执行任务的计算归属与依赖。

## A：主方法关键路径

A独立负责剩余共同池采集、自己的D/G0/Q数据视图与训练准备/训练、π0.5＋MT50本方法N/R/Post/Velocity主结果与H扫描（E4/E9）以及这些运行中的E5记录。A拥有完成主线所需的全部计划源，不等待B采集、B视图反馈、B基线完成、B daemon上线或B退出屏障。

共同池原500源中17个已处理、8个由当前Batch3独占保持原记录；其余475个尚未开始的源全部归A。此前V1计划中的B250只是未执行的分配，取消后转给A；同一source/seed不重生成、不重采。每任务仍8train＋2development，ASCII ordinal仍用于稳定身份/排序，不再用于把新源交给B。已经存在的真实claim必须先核对，不能依靠owner改写抢走活跃任务；本次核对未发现公共package或采集claim；B已有V1后台join-waiter，正在等待package，不等于采集daemon就绪。切换时保存该状态，V1 waiter不得领取V2归A的源。

正常采集批自动检查并发布。A原A12不再依赖B11；主结果冻结单独设P20_A，依赖A自己的模型和配置。A20的16个主结果单元全部在A队列分批完成，不再把必须回收的主结果分片放到B。未冻结的训练/评测方案仍需一次阶段配置冻结，但该冻结不以B状态为前置条件。

## B：外部对比、消融和适用性

B负责VLA-Corrector/GAF-v1 adapted外部方法的数据视图、训练和H10比较（E3），既有五任务的四损失消融（E1）及收益/异常触发最小对照（E6），SmolVLA/X-VLA＋MetaWorld和π0.5＋LIBERO适用性（E8）。相应E5记录随本机评测产生。B不采集本轮A共同池475源，不运行A主结果必需分片。

B当前可立即做：既有B11视图适配、读取16个已接受父源作真实接口验证、利用历史train600准备E1/E6，以及利用已有Smol50k、X初始化和LIBERO资产准备各自可执行任务与一次性阶段预算。不得把旧底座结果冒充本轮评测，不能自行恢复Smol100k或启动未冻结的新训练。

B按已具备输入的独立任务优先执行，某项缺数据时仅阻塞该项。外部方法正式公平比较须使用与A本方法相同冻结版本的共同训练池和相同评测源/协议；早期16源只用于接口/开发，不冒充终版同数据对比。数据依赖为B读取A已发布不可变快照，A无需等B消费或确认。

E3还须绑定相同π0.5 checkpoint、动作归一/执行协议、H10/总时域、环境资产和预定初始化身份；方法各自合法视图和历史初始化沿革单列，不声称全部训练历史相同。B基线配置及开发选模规则先锁定，读取A测试输入快照不包含A测试结局供调参；A无需等B锁定才运行。成功率按相同预定源配对并披露host，不以相同seed推断完整物理状态相等。

E5按host保存耗时；硬件/软件/并发/cold-warm条件不同时，跨host原始时延、GPU秒和time-per-success不能直接解释为算法效率排名。参数与策略调用次数可按统一定义比较。此次不为时延另增episode或重跑A主结果；可比性不足的时间指标只作为各自资源报告。

## 调度与资源隔离

- 节点队列、claim、进程组、发布及holder恢复屏障相互独立；只有最后论文汇总需要收齐两端结果，执行过程不设跨机同步屏障。基准合同第4节的“暂停整个阶段”限于确实受影响的授权阶段；B普通故障、其局部预算耗尽或B私有证据损坏不得触发A全局stop。共享存储只在短原子记账事务持锁，各node/job的容量预约可并存，不跨采集/训练、GPU预约、整批发布或等待持有跨机锁；锁未知时报告存储准入问题，不靠B人工ACK释放。
- B本机故障、缺依赖、适配失败或暂停，只影响B及其对应下游任务；不得由B状态自动暂停A。全局stop由分析/用户控制；共享输入确有损坏时各节点按自身身份门拒绝，不把普通B失败升级成A停止。
- B部署不作为A package验收或启动前提。A公共程序发布后自身通过即可运行；B可以晚接入。
- 共享存储预约按node/job记录。A主线优先：A仍有待采集源时，B新任务准入须保留A下一8源批93,952,475,136B的可用空间底线（扣除/避免重复计算已为A保留的额度）；B不得占用A私有cache/输出目录或删除A资产。逻辑预约不是硬quota，磁盘实际不足仍按既定门暂停相关新admission。
- 每节点以8卡真实任务为目标；独立阶段内可并行已冻结的种子/方法/源批次，不把等待B结果作为A GPU空闲的理由。正式任务期间禁止holder，只有本机无可执行任务且退出/发布完成才恢复。

本V2取消V1中B的250源采集权限和B首次采集parent计划；总待采集475源及所有科学操作总上界不增加。B后续模型训练/评测仍由各自一次性阶段授权控制，当前只授权队列接入和隔离CPU准备，不凭此补充扩大算法实验矩阵。
